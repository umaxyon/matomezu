- 詰まる所: AI が行うとき、Go は OS のタイムゾーンの IANA 名を取れない（Windows では time.Local の名前が "Local"）。取れるのは UTC との差（分）だけ
- 案: (a) IANA 名を載せ、ホストは画面の perform で最後に受けた名前を覚える（無ければ差から作った固定の値）／(b) 差（分）だけを載せる／(c) 利用者の日付（YYYY-MM-DD）を載せる。プラグイン API に見える形なので、page-create を作るときに refactor-review に見せてから決める
- システムフォルダで聞く事: 名前を定義の文言から引くとき、同じ名前の決まり（title-taken）にシステムフォルダの名前を入れるか（言語で名前が変わる）
- 2026-11-18 追記: Go の中のエンジンは goja で Intl が無い。IANA 名を ctx に載せても、常駐の行い直しで日付を出せない → 残るのは (b) 差（分）か (c) 日付そのもの。refactor-review に見せる
