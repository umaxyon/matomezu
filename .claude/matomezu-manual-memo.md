# matomezu 利用者マニュアル（下書き）

matomezu は、人と AI が同じ図を見て、直し合うための図エディタです。図は「ブック」にまとめて持ちます。ブックは 1 枚以上の「ページ」を持ち、ページは 1 枚の「紙」です。

## 1. 始める

### 入れる

【未確定】npm で入れるときのパッケージ名とコマンド。

### 起動する

1. `matomezu open` を実行する
2. ブラウザが開き、画面が出る

- 起動していなければ、起動してからブラウザを開きます
- 最初の画面は、コントロールセンターです（2 章）
- ブラウザで再読み込みしたときは、その前の画面に戻ります

`matomezu start` でも起動できます。

- 起動するだけで、ブラウザは開きません。出るのは URL（http://127.0.0.1:7230/）です
- 既に起動していれば、URL だけが出ます
- 一度 `matomezu open` で開いたブラウザなら、この URL を開いて使えます。初めてのブラウザには、「matomezu open で開く」という案内が（URL とは別に）出ます

注: 窓が 1 つも無いときに AI がブックを画面に出すと、matomezu がブラウザを開きます。そのブラウザも、そのまま使えます。窓が開いていれば、ブラウザは開きません。

### 使えるブラウザ

matomezu の画面を使えるのは、`matomezu open` で開いたブラウザ（または AI が画面に出すときに開いたブラウザ）だけです。ほかのブラウザで URL を開くと、画面に次の 1 行だけが出ます。

> ターミナルで matomezu open を実行してください

出たら、ターミナルで `matomezu open` を実行します。ブラウザが開き、そのブラウザが使えるようになります。

この 1 行が出るのは、次のようなときです。

- 初めて開いたとき
- 別のブラウザで開いたとき
- シークレットウィンドウで開いたとき
- ブラウザの cookie を消したとき

使えるようになったブラウザは、次のとおりです。

- matomezu を起動し直しても、使えるブラウザはそのままです
- 使えるブラウザは 20 件までです。超えると、長く使っていないブラウザから使えなくなります

注: この仕組みは、AI などがブラウザを通さずに、人のふりをして画面の操作をするのを防ぐためです。

### 止める

`matomezu stop` を実行します。

注: `matomezu serve` で起動すると、端末の手前で動きます。Ctrl+C で止めます。

### AI とつなぐ

AI には MCP でつなぎます。つなぐコマンドは `matomezu mcp` です。

- Claude Code は、matomezu のプラグインを入れてつなぎます。MCP の登録はプラグインが行います（16 章「Claude Code のプラグイン」）
- matomezu を起動し直したら、Claude Code では /mcp でつなぎ直します

【未確定】Claude Code のほかの AI への登録の書き方。

## 2. 画面の作り

### コントロールセンターとブックスクリーン

窓には、2 つの画面があります。前に出るのは、どちらか 1 つです。

- コントロールセンター: ブックに属さない物を見る画面。ワークルームと参加者・郵便・書庫・プロジェクトを見ます（下の「コントロールセンター」）
- ブックスクリーン: ブックを見て直す画面。ステージが並びます（下の「ステージ」）

matomezu を開いた直後は、コントロールセンターが前に出ます。後ろのブックスクリーンには、最初のブックが開いています。ブックが 1 冊も無ければ、ブックを開いていないステージです。

ブックスクリーンへ行く:

- コントロールセンターの下の行のボタン「コントロールセンター」を押す（押された状態のボタンです）
- Escape を押す
- ブラウザの戻るを押す

注: コントロールセンターで書庫とプロジェクトを替えたあとは、ブラウザの戻るで、先に前の画面に戻ります（下の「コントロールセンター」）。

コントロールセンターへ行く:

1. ステージの下の行のブックの名前にポインタを乗せる
2. 上がったフッタメニューの「コントロールセンター」を押す

- 行き来しても、ブックスクリーンの中（開いているブック・分割など）はそのまま残ります
- コントロールセンターの間でも、郵便から行き先を開いたり、まとめたしおりを押したりすると、ブックスクリーンが前に出ます（14 章）
- 郵便のダイアログは、コントロールセンターの上にも開きます。ダイアログを開いただけでは、ブックスクリーンは前に出ません（14 章「郵便のダイアログ」）
- 左サイドパネルは、どちらが前に出ていても残ります（下の「左サイドパネル」）
- 新しいブックは、ブックを開いていないステージで作ります（3 章）
- 設定画面は、フッタメニューの「設定を開く」で開きます（15 章）

注: コントロールセンターが前に出ている間は、後ろに開いているブックを見ている事になりません。郵便の行き先が後ろに開いていても、見た事になりません。ブックスクリーンへ戻ると、見た事になります。

### コントロールセンター

コントロールセンターは、左の列と右の領域に分かれます。

左の列（上から）:

1. 利用者パネル
2. 「プロジェクト」の一覧（18 章「プロジェクトの一覧」）
3. 「ワークルーム/参加者」の一覧（16 章「ワークルームの一覧」）

利用者パネルに出る物:

- 帯: 「コントロールセンター」と、歯車「全体設定」
- 「あなた」
- 4 つのボタン: 郵便・書庫・プロジェクト・横断検索（虫メガネ）

| 押す物 | 起きる事 |
|---|---|
| 全体設定（歯車） | 設定画面が開く（15 章） |
| 郵便 | 左サイドパネルの郵便箱を開く。もう一度押すと閉じる |
| 書庫 | 右の領域に書庫の画面を出す |
| プロジェクト | 右の領域にプロジェクトの画面を出す |
| 横断検索（虫メガネ） | 左のサイドパネルに「横断検索」が開く（19 章） |

- 押されている間のボタンは、押された状態になります。郵便は、左サイドパネルの郵便箱が開いている間です
- ボタンにポインタを乗せると、名前が出ます

右の領域には、プロジェクトの画面か書庫の画面の、どちらか 1 つが出ます。

- 初めは、プロジェクトの画面です
- 書庫・プロジェクトのボタンで替えると、新しい画面が上から滑り込みます
- ブラウザの戻るを押すと、前の画面に戻ります
- 読み直しても、出ていた画面のままです

プロジェクトの画面:

- 上: タスクボード。プロジェクトの一覧でチェックしたプロジェクトのボードが、縦に並びます（18 章「ボード」）
- 下: ワークルームの枠。一覧で選んだワークルームが出ます（16 章「ワークルームの枠」）

ボードかレーンを最大化している間は、左の列とワークルームの枠が画面の外へ退きます（18 章「最大化」）。

書庫の画面:

- 題「書庫」の帯と、右上の「最大化」のボタンだけです。中身はまだありません
- 「最大化」を押すと、書庫の画面が広がり、左の列が隠れます
- 「元に戻す」を押すと、左の列が戻ります

注: 郵便のボタンで開いた郵便箱は、ステージのフッタメニューの「左サイドパネルを開く」で開いたものと同じです（下の「左サイドパネル」）。
注: コントロールセンターの上には、チケットスクリーンが重なることがあります。重なっている間、コントロールセンターは操作できません（18 章「チケットスクリーン」）。

### ステージ

ブックを見て直す区画をステージと呼びます。画面を分割しなければ、画面全体が 1 つのステージです。

- 左上の丸いボタン: ツールを切り替えます（6 章）
- 下の行: ブックの名前と、ページのタブが並びます。タブを押すと、そのページを開きます。タブの並びの右端の＋で、ページを足します。タブはドラッグで並べ替えられます（4 章）
- 左の列（スライドのブックだけ）: ページ一覧です。ページのサムネイルが縦に並びます（4 章「ページ一覧」）

注: スライドのブックでは、下の行にページのタブが出ません。ブックの名前は出ます。フッタメニューも同じように上がります。

### フッタメニュー

下の行にポインタを乗せるか、ブックの名前を押すと、下からフッタメニューが上がります。左から次が並びます。

1. 地図: ミニマップと、拡大・縮小の帯
2. 元に戻す・やり直すのボタン
3. 基本のボタン: コントロールセンター（上の「コントロールセンターとブックスクリーン」）、画面を分割（分割中は分割をやめる）、ブックを開く、ブックの設定、設定を開く（歯車。15 章）、印刷区画の区切り（可変ページで印刷区画が 2 つ以上あるときだけ。4 章）、印刷プレビュー（12 章）、左サイドパネルを開く（下の「左サイドパネル」）
4. ツールボックス: 紙に置くアイテムを選びます（7 章）。右に「スクラップトレイを開く」のボタンが並びます（図面・フローチャートだけ。20 章「スクラップトレイ」）

### 左サイドパネル

窓の左端に出す区画です。開くと、右の画面（ブックスクリーンかコントロールセンター）が左サイドパネルの幅だけ狭まります。画面の上には重なりません。

1. ステージのフッタメニューの「左サイドパネルを開く」を押す
2. 窓の左に左サイドパネル（幅 400px）が出る。上にタブが並ぶ
3. 一番左のタブ「郵便箱」が開く
4. タブを押すと、中身が替わる

タブ（左から）:

- 郵便箱: AI から届いた郵便（14 章）
- 送信トレイ: 開くボタンを押したステージで開いているブックの、伝言とマーク（13 章「送信トレイ」）

注: スクラップトレイも左サイドパネルに開きます。開き方が違い、フッタメニューの「スクラップトレイを開く」で、トレイだけが開きます。ステージのブックが置けないタイプに替わると閉じます（20 章「スクラップトレイ」）。

まだ見ていない郵便があると、その数が「左サイドパネルを開く」の角と、郵便箱のタブの名前の横に出ます（14 章「未読の数」）。

- 開いたまま、コントロールセンターを前に出せます。左サイドパネルは残ります
- 画面を分割していても、両方のステージが見えたまま、まとめて狭まります
- 右サイドパネルと一緒に開けます。左サイドパネルを押しても、右サイドパネルは閉じません
- ステージで開いているブックが替わっても閉じません。送信トレイの中身が、そのブックのものに替わります

注: 窓の幅が 400px 以下なら、左サイドパネルが窓の幅いっぱいになり、右の画面は見えなくなります。

分割しているとき:

- 開いた側と別のステージの「左サイドパネルを開く」を押すと、閉じずに、送信トレイがそのステージのブックに替わります。開いているタブはそのままです
- 「左サイドパネルを開く」が押された印になるのは、開いた側のステージのボタンだけです

閉じる:

- 左サイドパネルの右上の × を押す
- 開いたステージの「左サイドパネルを開く」をもう一度押す
- 左サイドパネルの中で Escape を押す
- 郵便のダイアログの「郵便箱も閉じる」を押す（14 章「郵便のダイアログ」）

注: 左サイドパネルの外を押しても閉じません。送信トレイの行を押しても閉じません。
注: コントロールセンターでは、利用者パネルの「郵便」で開きます（上の「コントロールセンター」）。まとめたしおり（14 章「しおり」）からも開きます。

### 画面を分割する

1. フッタメニューの「画面を分割」を押す
2. 右に空のステージが足される
3. 真ん中の「ブックを選択してください」でブックを選んで開く

注: 空のステージの「新しいブック」でブックを作ることもできます。作ったブックは、そのステージで開きます（3 章）。

- 左右に 2 つまで分けられます。同じブックも別のブックも開けます
- 境目はドラッグで動きます。ダブルクリックで真ん中に戻ります
- 各ステージの右上の × で、そのステージを閉じます
- 「分割をやめる」で、今のステージだけを残します

### 右クリックのメニュー

| 右クリックする所 | 出る項目 |
|---|---|
| 紙の何も無い所（図面・フローチャート） | ページ全体を収める・初めの位置に戻す・画面を分割（分割中はステージを閉じる） / 貼り付け / スクラップを切り抜く（20 章）・ページの設定・ブックの設定（フローチャートは、区切りの下に自動で整列） |
| 紙の何も無い所（ツリー・ディレクトリ構成図） | ページ全体を収める・初めの位置に戻す・画面を分割（分割中はステージを閉じる） / スクラップを切り抜く（20 章）・ページの設定・ブックの設定 |
| ページのタブ | ここに追加・スクラップを切り抜く（20 章）・背景を編集（背景のあるタイプだけ。10 章「背景」） / 削除… |
| 箱・形・絵・リスト・データ・スクラップ | 設定・元のページを開く（スクラップだけ。20 章） / 切り取り・コピー・貼り付け / 削除（7 章「コピー・切り取り・貼り付け・複製」） |
| 線 | 設定・削除 |
| リストの行 | 行の編集・行を削除 |
| ページ一覧のページ（スライド） | ここに追加・複製・スクラップを切り抜く・削除…（4 章「ページ一覧」） |
| スライドの文字枠・自由な線・直線・楕円 | 最前面へ・1 つ前へ・1 つ後ろへ・最背面へ・消す（10 章「スライド」の「重なり順」） |
| マークダウンの上の行・ペインの見出し・プレビューのペイン | 画面を分割・ステージを閉じる / スクラップを切り抜く・ページの設定・ブックの設定（10 章「マークダウン」） |

箱・形・絵・リスト・データ・線・リストの行・ツリーの節・ディレクトリ構成図の行では、メニューの最後に区切り線を挟んで「AIに伝言」「AIに示す」が出ます（13 章）。

注: プラグインで足した物で、右クリックのメニューを持たない物でも、「AIに伝言」「AIに示す」だけのメニューが出ます。

注: 伝言の吹き出しと、物の右上の角に出る印は、右クリックしても何も出ません（13 章）。

注: 図面とフローチャートで、いくつか選んでいる物の 1 つを右クリックすると、メニューは選んでいる物の全部に効きます。このとき「設定」は出ません（7 章「選ぶ」）。

- メニューは、右ボタンを離したときに出ます。押し続けると、メニューではなくツールのアイコンが出ます（6 章）
- Escape か Space で閉じます

## 3. ブック

### 新しいブックを作る

1. ブックを開いていないステージの、真ん中の「新しいブック」を押す
2. ブックの名前と、ブックのタイプを決める
3. タイプによっては「（タイプ）の設定」も決める
4. 「作成」を押す
5. 作ったブックが、そのステージで開く

注: ステージが 1 つだけで、ブックを開いていないステージが無いときは、先にフッタメニューの「画面を分割」を押します。右に出た空のステージで作ります（2 章「画面を分割する」）。

ブックのタイプは、図面・フローチャート・ツリー・ディレクトリ構成図・マークダウン・スライドの 6 つです（10 章）。

注: 入れているプラグインが、あるタイプのブックを作るのを止めていると、そのタイプは「ブックのタイプ」に出ません（17 章）。

### ブックを開く

フッタメニューの「ブックを開く」で、ブックの一覧から選んで開きます。

- ブックは、最後に触れた（開いたか書き換えた）のが新しい順に並びます。時刻は、そこからの経過で出ます
- 名前の無いブックは「名前なし」と出ます
- 開けないブックは理由が出ます（タイプが無い・形に合わない・決まりを守っていない）

「一部表示できない物があります」と出たとき:

- ブックに、今の matomezu に入っていないプラグインの物が含まれています
- ブックは開けます。ほかの物は普通に見られ、直せます
- 表示できない物は消えずに残り、紙の上では枠だけで描かれます
- 直し方は、作った人か AI に相談してください

### ブックの設定

フッタメニューの「ブックの設定」か、紙の何も無い所の右クリックで開きます。

- ブックの名前
- テーマ: 選べるテーマは、ブックのタイプで違います（下の表）。どのタイプも標準が既定です
- 紙の色
- 文字の色: 本文の装飾の 4 色を、このブックでは何色で描くか（7 章）
- 線の既定の通り方（図面とフローチャートだけ。9 章）

| ブックのタイプ | 選べるテーマ |
|---|---|
| 図面・フローチャート・ツリー・ディレクトリ構成図・スライド | 標準・付箋紙・シンプル・matomezu |
| マークダウン | 標準・GitHub 風 |

テーマの matomezu は、マスコットの鳥の色のテーマです。本文の装飾の 4 色（成功・情報・注意・エラー）も、鳥の色で描きます。

テーマの GitHub 風は、GitHub の Markdown に似せた見た目です（10 章「マークダウン」）。

注: ブックの設定と利用者の設定の「文字の色」で色を決めていれば、そちらが効きます。

注: 入れているプラグインのテーマは、そのテーマが向くタイプのブックでだけ選べます。

注: マークダウンのブックの設定は、ブックの名前・テーマ・紙の色だけです。

注: スライドのブックの設定は、ブックの名前・テーマ・紙の色と「スライドの印刷」です（10 章「スライド」）。

注: 印刷プレビューの設定（紙を並べる向きなど）は、ブックの設定には出ません。印刷プレビューの右サイドパネルで変えます（12 章）。

### ゴミ箱

「ブックを開く」のダイアログの上で「ブック」と「ゴミ箱」を切り替えます。

- ゴミ箱に入れる: 「ブック」の一覧で、行にポインタを乗せると右に「ゴミ箱に入れる」が出ます
- 戻す: 「ゴミ箱」の一覧の「戻す」で、ブックの一覧に戻します
- 削除: そのブックを完全に消します
- ゴミ箱を空にする: ゴミ箱のブックを全部、完全に消します

完全に消す前に、確かめが出ます。

注: そのブックに行えないときは、その行の「戻す」「削除」が薄くなって押せません（例: 入れているプラグインが止めているとき。17 章）。「ゴミ箱を空にする」は押してから確かめます。

注: 押したあとで断られたときは、「戻せません」「消せません」と出ます。プラグインが止めたときは、その代わりに止めた仕組みの名前が出ます。

注: 次のブックには「ゴミ箱に入れる」が出ません。

- ロック中のブック
- ロック中のページを持つブック
- 入れているプラグインが、ゴミ箱に入れるのを止めているブック（17 章）

## 4. ページ

### ページを足す

1. 下の行の、タブの並びの右端の＋（ページを足す）を押す
2. 「新しいページ」のダイアログで中身を決める
3. 「作成」（ツリーとディレクトリ構成図は「作る」）を押す

| ブックのタイプ | 決める物 |
|---|---|
| 図面・フローチャート | ページの名前・紙のサイズ（A5・A4・A3・レター・タブロイド・スライド用(16:9)）・向き・可変ページにする（図面は増やす向きも） |
| ツリー | ページ名・伸びる向き・根のキャプション |
| ディレクトリ構成図 | ページ名・根のフォルダの名前（初めはページ名） |
| マークダウン | ページの名前・紙のサイズ・向き |
| スライド | 【未確定】決める物。紙は初め「スライド用(16:9)」の横 |

ページが 1 枚も無いブックでは、紙の真ん中に「ページがありません」と出ます。「ページを作る」から足せます。

注: スライドのブックには、ページのタブも、その右端の＋もありません。ページ一覧の＋か右クリックで足します。このときダイアログは出ません（下の「ページ一覧」）。表の「スライド」の行は、ページが無いときの「ページを作る」の事です。

### ページを並べ替える

下の行のページのタブを、ドラッグで並べ替えます。

1. タブを押したまま、横に動かす
2. 掴んだタブは元の所で薄くなり、タブの写しがポインタに付く
3. 落とす所に縦の線が出る
4. 入れたい所で離す

- タブの並びの外で離すと、動かしません
- タブが横にあふれているときは、並びの端へ寄せている間、タブの並びがスクロールします
- 元に戻す・やり直すで、並びも戻ります（11 章）
- ロック中のページも動かせます
- ロック中のブックでは、動かせません

注: スライドのブックでは、ページ一覧のサムネイルを縦にドラッグして並べ替えます（下の「ページ一覧」）。

### ページ一覧（スライドのブック）

スライドのブックでは、ステージの左の列に、ページのサムネイルが縦に並びます。ページのタブの代わりです。

- 各サムネイルの左に、ページの番号が出ます
- 開いているページは、サムネイルに青い枠が付き、番号が太字になります
- 列の幅は、ステージの幅の 15% です（72px から 180px まで）
- ページが多いときは、列が縦にスクロールします
- ロック中のページには、番号の下に鍵の印が付きます

注: サムネイルの大きさは、ステージの拡大・縮小では変わりません。

開く:

- サムネイルを押すと、そのページを開きます

並べ替える:

1. サムネイルを押したまま、上下に動かす
2. 掴んだサムネイルは元の所で薄くなる
3. 落とす所に横の線が出る
4. 入れたい所で離す

注: ページのタブの並べ替えと同じく、ロック中のブックでは動かせません（上の「ページを並べ替える」）。

足す:

- 列のいちばん下の＋を押すと、最後にページを足して開きます（ページが 0 枚のときも出ます）
- サムネイルを右クリックして「ここに追加」を押すと、そのページのすぐ後ろに足して開きます

足したページの名前は「（無題）」です。紙は「スライド用(16:9)」の横です。名前は、ページの設定で変えます（上の「ページの設定」）。

複製する:

1. サムネイルを右クリックする
2. 「複製」を押す
3. 同じ中身のページが、すぐ後ろにでき、開く

- 名前は元のページと同じです
- ロックは写りません
- 伝言とマークは写りません（13 章）

削除する:

1. サムネイルを右クリックする
2. 「削除…」を押す
3. 「ページを削除」のダイアログに「（ページの名前）: ページと中身が消えます」と出る。「削除」を押す

- ロック中のページでは、右クリックの「複製」と「削除…」が灰色になり、押せません

### ページの設定

紙の何も無い所の右クリック「ページの設定」で開きます。名前などを変えます。ブックのタイプによって、変えられる項目が増えます。

注: マークダウンのブックには紙がありません。上の行・ペインの見出し・プレビューのペインの右クリック「ページの設定」で開きます（10 章「マークダウン」）。

どのタイプでも、次の項目を変えられます。

- 紙のサイズ・向き: 選べる物が 1 つしか無いタイプでは、選べません
- 可変ページにする（4 章「可変ページ」）

形が紙に入らなくなる値を選ぶと「形が紙に入りません」と出て、確定できません。

### 可変ページ

ふつうのページは、紙 1 枚の大きさに決まっています。「可変ページにする」をオンにしたページは、中身が広がるのに合わせて、紙と同じ大きさの印刷区画を足して広がります。

可変ページにする:

- ページを足すとき: 「新しいページ」のダイアログの「可変ページにする」をオンにする（図面・フローチャート）
- 後から: ページの設定の「可変ページにする」をオンにする（どのタイプも）

広がる向きは、ブックのタイプで決まります。

| ブックのタイプ | 広がる向き |
|---|---|
| 図面 | 「増やす向き」で選ぶ: 右と下（初め）・右だけ・下だけ・上下左右 |
| フローチャート | 流れの向きで決まる: 下へなら左・下・右、右へなら上・下・右 |
| ツリー | 伸びる向きで決まる: 根のある側を除いた 3 つの向き。中央からなら上下左右 |
| ディレクトリ構成図 | 右と下 |
| マークダウン | 下だけ |

注: マークダウンのページは、いつも可変ページです。「可変ページにする」は出ません。

紙の上の見え方:

- 広がる向きには、いつも空きの印刷区画が 1 つ付きます。そこにも物を置けます
- 印刷区画の境目には破線が引かれます
- 何も載っていない印刷区画は、薄く暗くなります。暗い印刷区画は印刷しません（12 章）

注: 図面・フローチャートでは、物が少しでもかかる印刷区画と、線を手で直した折れ目がある印刷区画が「載っている」印刷区画です。
- 上や左へ広がるページでは、上や左の空きの印刷区画に物を置くと、中身が印刷区画の単位で右や下へずれます。画面の上では、中身は見えている所に留まります
- 上や左へ広がるページを開くと、中身の載った印刷区画が見えます。上や左の空きの印刷区画は、紙をずらすと見えます（6 章「初めの位置」）

印刷区画の区切りを隠す:

1. フッタメニューの「印刷区画の区切り」を押す
2. 破線が消える。もう一度押すと出る

- 隠したかどうかは、ステージごとに覚えます。ブックには残りません

可変ページをやめる:

1. ページの設定の「可変ページにする」をオフにする
2. 「確定」を押す

- 上や左の空きの印刷区画は詰めます
- 形が紙 1 枚に入らなければ「形が紙に入りません」と出て、やめられません。中身を紙 1 枚に収めてからオフにします

注: 増やす向きを変えたときも、広げなくなった向きの空きの印刷区画は詰めます。その向きで形が紙からはみ出すなら、変えられません。

### ページを削除する

1. ページの設定を開く
2. 「ページを削除」を押す
3. 「ページと中身が消えます」と出る。「削除」を押す

- 最後の 1 枚も消せます
- ロック中のページは消せません

## 5. ロック

ブックやページの中身を、人からも AI からも変えられなくします。

1. ブックの設定か、ページの設定を開く
2. 見出しの右の鍵のボタンを押す
3. 「確定」を押す

- ロック中は、ブックの名前とページのタブに鍵の印が付きます
- 外すときも、同じ鍵のボタンを押して「確定」します。ロックを外せるのは人だけです
- ロック中でも、伝言とマークは付けられます（13 章）
- 印刷プレビューの右サイドパネルでも、ブックのロックを掛け外しできます（12 章）

注: ページのタブの並べ替え（4 章）は、ページのロックでは止まりません。止まるのはブックのロックだけです。

## 6. 見る・ツールを切り替える

### 拡大・縮小

フッタメニューの地図にある帯で操作します。左から次が並びます。

1. 初めの位置に戻す（Home）
2. ページ全体を収める
3. 縮小
4. 倍率
5. 拡大

- 拡大・縮小のボタンは 10% ずつ変わります。30% から 180% までです。端ではボタンが押せません
- Ctrl（Mac は ⌘）を押しながらホイールを回すと、ポインタの下を中心に、なめらかに変わります
- 可変ページでは、「ページ全体を収める」は印刷区画の全部を収めます

注: 印刷プレビューの間は、帯がフッタメニューではなく右サイドパネルに出ます（12 章）。

【未確定】ピンチでの拡大・縮小。

### 初めの位置

ページを開くと、倍率 100% で、紙の左上が表示領域の左上に来ます（周りに少し余白が付きます）。「初めの位置に戻す」（帯のボタン・Home キー）も、この見え方に戻します。

- 上や左へ広がる可変ページでは、中身の載った印刷区画のうち、いちばん左・いちばん上の所が表示領域の左上に来ます。上や左の空きの印刷区画は、画面の外になります
- 読み直したときや、ブラウザの戻る・進むでは、前に見ていた位置と倍率のままです
- 開いていたページが削除されて隣のページが開いたときも、初めの位置で開きます
- 印刷プレビューの間に「初めの位置に戻す」を押すと、並べた印刷区画の左上に戻ります

注: 何も載っていない可変ページでは、紙の左上が表示領域の左上に来ます。

### ホイールで紙をずらす

- ホイールを回すと、紙が上下にずれます
- Shift を押しながら回すと、紙が左右にずれます

ポインタの下に中でスクロールする物があるときは、そちらが先にスクロールします。中でスクロールする物は次の 2 つです。

- 行がリストの高さを超えたリストの、行の所
- 中でスクロールしているデータの表

1. その物がまだスクロールできる間は、その物だけがスクロールします。紙はずれません
2. 端に着いても、そのまま回し続けている間は紙はずれません
3. 手を止めて（0.3 秒ほど）次に回すと、紙がずれます

注: 紙をずらしながら回し続けている間は、ポインタがリストや表の上に来ても、紙がずれ続けます。

注: Shift を押しながら回したときは、横にスクロールする物の上でなければ、紙が左右にずれます。

### ミニマップ

フッタメニューの地図に、開いているページの紙の全体が小さく出ます（可変ページなら印刷区画の全部）。今見えている範囲は四角で重なります。

- 四角をドラッグすると、見る所がついて動きます
- 四角の外を押すと、そこが真ん中に来ます。そのままドラッグもできます

ツールの切り替え（Space か、紙の上で右ボタンの長押し）を出したときにも、ツールのアイコンと一緒に、同じミニマップと拡大・縮小の帯が出ます（下の「ツール」）。

注: 窓が低いなど、入る場所が無いときは出ません。

注: 四角をドラッグしている間は、ミニマップの外へ出ても閉じません。

### ツール

ツールの組は、ブックのタイプごとに決まっています。

| ブックのタイプ | ツール |
|---|---|
| 図面 | 選択ツール・付け替えツール・ハンドツール |
| フローチャート | 選択ツール・ハンドツール |
| ツリー | 編集ツール・ハンドツール |
| ディレクトリ構成図 | 鉛筆・ハンドツール |
| マークダウン | なし |
| スライド | 【未確定】 |

切り替え方:

- ステージの左上の丸いボタンを押すと、次のツールに替わります
- Space を押すか、紙の上で右ボタンを長押しすると、ポインタの近くにツールのアイコンが並びます（ツールの切り替え）。アイコンを押すと、そのツールに替わります。Escape か外を押すと閉じます
- アイコンの並びの外側（ポインタと反対の側）には、ミニマップと拡大・縮小の帯も出ます。フッタメニューの地図と同じように使えます（上の「ミニマップ」）
- アイコンに乗ると、アイコンとポインタの間にツールの名前が出ます
- ポインタがアイコンとミニマップから離れると閉じます

注: 右ボタンを押している間は、ポインタの周りに輪が満ちていきます。満ちるとアイコンが出ます。出るまでの時間は、設定画面の「全体」で変えられます（15 章）。

使えないツールは、アイコンに斜線が付きます。

各ツールでできること:

- 選択ツール: アイテムを置く・押して選ぶ・何も無い所からドラッグして範囲で選ぶ・ドラッグで動かす・大きさを変える・線を引く・ダブルクリックで編集する
- ハンドツール: 紙をドラッグして、見る所をずらします。アイテムは選べません
- 付け替えツール: アイテムを箱の中へ入れる・外へ出す（7 章）
- 編集ツール: ツリーの節を操作します（10 章）
- 鉛筆: ディレクトリ構成図の行を操作します（10 章）

## 7. アイテムの基本

紙の上に置く物をアイテムと呼びます。箱・リスト・形・絵・データ・線・スクラップがあります。

注: スクラップはツールボックスに無く、スクラップトレイから置きます（20 章）。

注: スライドのブックに置く物（文字枠・自由な線・直線・楕円）は、置き方も直し方もこの章と違います。10 章「スライド」を見てください。

### 置く

1. フッタメニューのツールボックスで、置くアイテムを押す（何があるかは 10 章）
2. 紙の上で点線の箱が出る。点線の箱は、今押すと置かれる所に出る。置きたい所で押す
3. 追加のダイアログが出る。中身を書いて「追加」を押す

- ツールボックスでもう一度押すか、Escape で、置くのをやめます
- 置けない所では、点線の箱が薄くなります。押しても置きません
- 線はツールボックスにありません。箱から引きます（9 章）
- データは追加のダイアログが出ず、そのまま置かれます（8 章）

押した所に何があるかで、置く先が変わります。点線の箱も、その置く先に出ます。

- 何も無い所: 押した所に置きます
- 図面の箱の上: その箱の中に置きます。置こうとしている間、入る先の箱に枠が出ます
- リスト・形・絵・データなど、中に入れられない物の上: その物と同じ所（箱の中か紙の上）の空きに置きます。空きは左上から、左から右へ、次に下へと探します

注: 箱の中では、キャプションの所などで押すと、中のアイテムが並ぶ所の端へ寄せて置きます。点線の箱も寄せた所に出るので、ポインタから離れることがあります。
注: 空きに置くときも、点線の箱はポインタから離れた空きに出ます。追加のダイアログのあるアイテムは、書いた中身の大きさで空きを探し直すので、点線の箱と少しずれた所に置かれることがあります。
注: 置いた所で近くの物に近づきすぎると、その物が押しのけられます。

置けないとき:

- 紙からはみ出す所: 点線の箱が薄くなり、押すと「紙に収まりません」と出て、置きません
- 押しのけた物や、大きくなった箱が紙からはみ出す所: 同じく点線の箱が薄くなり、押すと「紙に収まりません」と出ます。箱の中に置くときも同じです
- 空きが無いとき: 点線の箱が薄くなり、押すと「空きがありません」と出ます

追加のダイアログのあるアイテム（箱・リスト・形・絵）は、ダイアログで書いた中身の大きさで、「追加」を押したときにもう一度確かめます。置けなければ、ダイアログは閉じずに、その中にわけが出ます。

- 空きに置くとき、その大きさの空きが無い: 「空きがありません」
- それ以外で紙に収まらない: 「紙に収まりません」

注: 点線の箱は、中身を書く前の大きさで置けるかを見ます。中身を書いて大きくなると、点線の箱が濃い所でも、ダイアログで断られることがあります。

### 選ぶ

図面とフローチャートでは、選択ツールで次のように選びます。

- 押す: そのアイテムだけを選びます
- Mod+クリック: 押したアイテムや線を選択に足します。選んでいる物を Mod+クリックすると、選択から外します
- 範囲で選ぶ: 何も無い所からドラッグすると、四角が出ます。四角に少しでもかかったアイテムと、両端がどちらもそのアイテムの線を選びます。Mod を押しながらなら、前の選択に足します
- すべて選択（Mod+A）: 開いているページのアイテムと線を全部選びます
- 何も無い所を押す: 選択を外します

Mod は、Windows・Linux では Ctrl、Mac では ⌘ です。

- いくつか選んでいるとき、その 1 つを押して動かさずに離すと、その 1 つだけの選択になります
- いくつか選んでいる間は、大きさ・本文の幅・項目の文字の領域のつまみは出ません。1 つだけ選ぶと出ます

注: 範囲で選ぶ・すべて選択では、箱の中に入れたアイテムは選ばれません。箱の中のアイテムは、押すか Mod+クリックで選びます。
注: 外すのは、Mod+クリックで動かさずに離したときです。そのままドラッグすると、外さずに動かします。
注: 箱の中のアイテムと、ほかの箱のアイテムや箱の外のアイテムを Mod+クリックで一緒に選ぶと、中のアイテムの代わりに、そのアイテムを入れた箱が選ばれます（一緒に動かせるように、どれも同じ階層にそろえます）。
注: リストの行の選び方は 8 章「リスト」です。伝言を書いている間の選び方は 13 章です。

### 動かす

- ドラッグで動かします。いくつか選んでいれば、選んでいる物をまとめて動かします
- 1 つだけ動かすとき、正面からほかの箱に半分以上重ねると、入れ替わります

注: 線は、両端のアイテムに付いて動きます。両端をまとめて動かした線は、手で直した通り方のまま動きます。
注: 置いたり大きくしたりして近くの箱に近づきすぎると、その箱が押しのけられます。押しのけた箱が紙からはみ出すなら、置いたり大きくしたりできません。
注: 置く・大きさを変えるなどで紙からはみ出す操作はできません。「紙に収まりません」と出ます。ドラッグで動かすときは、下の「離した所に収まらないとき」です。

離した所に収まらないとき:

ドラッグを離した所に収まらなければ、元の場所へは戻りません。収まる一番近い所に落ちます。

- 紙の端の外で離した: 紙の端に落ちます。斜めに出したときは、端に沿った所に落ちます
- 箱の中のアイテムを、その箱の中の左や上の外で離した: 箱の中の端に落ちます
- ほかのアイテムに近すぎる所・箱が大きくなれない所で離した: 動かし始めた所の方へ戻り、最初に収まる所に落ちます

注: どこにも収まらなければ、動きません。
注: AI が動かすときは、寄せません。収まらなければ断られます（16 章）。

### 大きさを変える

1 つだけ選んで、四辺か四隅をドラッグします。つかめる所に印は出ず、ポインタの形が変わります。

- 箱・リスト・形: 縦も横も変えられます
- 絵: 左右の辺だけです。高さは中身で決まります
- スクラップ: 四隅だけです。縦横の比を保って変わります（20 章「置いたスクラップの大きさを変える」）

注: 中にアイテムを入れた箱は、中のアイテムが入る大きさより小さくなりません。ドラッグはその大きさで止まります。

### 編集する・消す

- ダブルクリックか、右クリックの「設定」で、編集のダイアログを開きます。ダブルクリックしたアイテムだけの選択になります
- 右クリックの「削除」か、Delete・Backspace で消します。いくつか選んでいれば、選んでいる物を全部消します。箱やリストを消すと、中の物と、それにつながる線も消えます

注: いくつか選んでいる間は、右クリックのメニューに「設定」が出ません。編集するときは、ダブルクリックするか、1 つだけ選んでから右クリックします。

### コピー・切り取り・貼り付け・複製

図面とフローチャートで、選んだアイテムを写して、別の所に貼ります。

コピーして貼る:

1. アイテムを選ぶ（7 章「選ぶ」）
2. Mod+C を押す（コピー）
3. Mod+V を押す（貼り付け）
4. 写したアイテムが増え、貼ったアイテムが選ばれる

- 切り取り（Mod+X）: 写してから、選んだアイテムを消します
- 複製（Mod+D）: 選んだアイテムを、元の少し右下に 1 回で写します。写しは覚えません

右クリックのメニューからもできます。

- アイテムを右クリック: 切り取り・コピー・貼り付け
- 紙の何も無い所を右クリック: 貼り付け（右クリックした所に貼ります）

注: 写したものが無い間は、「貼り付け」は薄くなって押せません。

写るもの:

- 選んだアイテム
- 箱の中に入れたアイテム（中のアイテムごと写ります）
- 両端がどちらも写したアイテムの線

注: 写さなかったアイテムへつながる線は写りません。

貼る所:

| 貼り方 | 貼る所 |
|---|---|
| 紙の右クリックの「貼り付け」 | 右クリックした所 |
| Mod+V（何も選んでいないか、いくつか選んでいる） | 紙の空いている所 |
| Mod+V（箱を 1 つ選んでいる） | その箱の中 |
| Mod+V（箱でないアイテムを 1 つ選んでいる） | そのアイテムの右隣 |
| アイテムの右クリックの「貼り付け」 | Mod+V と同じ（右クリックしたアイテムが選ばれるため） |

- 貼る所に収まらなければ、収まる一番近い所に貼ります
- 近くの物に近づきすぎると、その物が押しのけられます（7 章「置く」）
- どこにも収まらなければ、貼らずに「紙に収まりません」と出ます

注: 箱の中に貼れるのは図面だけです（7 章「箱の中に入れる」）。

写しの持ち方:

- 写しは、その窓が覚えています。別のページや別のブックを開いても貼れます
- 何度でも貼れます
- 画面を読み込み直すと、写しは消えます

注: 写しはパソコンのクリップボードには入りません。ほかの窓・ほかのアプリ・別のパソコンには貼れません。

写せないもの:

- データ（8 章「データ」）。コピー・切り取り・複製を押すと、「コピーできません」と出ます
- データを中に入れた箱も、同じく写せません

元に戻す（11 章）:

- 貼り付け・切り取り・複製は、どれも 1 段で戻ります
- コピーはブックを変えないので、元に戻すの並びに入りません

キーは、設定画面の「ショートカットキー」の「ステージ」の下で変えられます（15 章）。

### 箱の中に入れる（図面だけ）

1. 付け替えツールに切り替える
2. アイテムをドラッグして、箱の上で離す

- 中に入れられるのは、図面の「箱」だけです
- 外で離すと、紙の上に出ます
- 新しく置くアイテムを、はじめから箱の中に置くこともできます（「置く」）
- 選択ツールのドラッグでは、箱の中に入りません
- 箱は中身に合わせて大きくなります

離した所に入れられないとき（箱が大きくなると紙からはみ出すなど）は、入れられる一番近い所に入れます。

- 箱の上で離した: 箱の中の左上の方へ寄せて、最初に入れられる所に入れます
- 外で離した: 動かす前の所の方へ寄せて、最初に置ける所に出します
- 同じ箱の中で動かした: 選択ツールのドラッグと同じです（上の「動かす」の「離した所に収まらないとき」）

注: どこにも入れられなければ、何も変わりません。
注: AI が箱に入れる・出すときは、寄せません。入れられなければ断られます（16 章）。

### ダイアログ

- 1 行の欄では、Enter でダイアログを決めます（確定・追加など）
- 本文のように何行も書ける欄では、Enter は改行です
- Escape は、どの欄の中でもダイアログを閉じます（取り消し）

箱・リスト・形・絵の追加と編集のダイアログで、決めても変えられないときは、ダイアログは閉じずに、変えられないわけが出ます。

- 紙に収まらないとき: 「紙に収まりません」
- 追加で空きに置くとき、空きが無い: 「空きがありません」（7 章の「置く」）
- ロック中のとき: 「ロック中」

### 色を選ぶ

色の丸を押すと、ポップアップが開きます。

- 上: 見本の「テーマの色 1〜6」（そのブックのテーマの代表色）と「なし」。「なし」はテーマの塗りに任せます。縁が点線です
- 中: 「濃さと明るさ」の四角と、「色合い」「灰色」のスライダー
- 下: 「色の値（#rrggbb）」

外を押すか Escape で閉じます。

### 本文の装飾

本文の欄のすぐ上に、装飾のボックスが出ます。その場で書くときは、入力欄の上に出ます。

- B: 太字
- 色の丸 4 つ: 文字の色（成功・情報・注意・エラー）
- 色なし: 文字の色を外します

字を選んで押すと、その範囲に付きます。付いていれば外れます。選ばずに押すと、次に書く字から付きます。

装飾のボックスが出る所:

- 箱のダイアログの本文
- リストの行のダイアログの本文
- ツリーの根の本文と、節をその場で書くとき
- ディレクトリ構成図の名前・説明をその場で書くときと、ノードの設定

4 色が実際に何色で描かれるかは、ブックのテーマで決まります。ブックの設定と利用者の設定の「文字の色」で変えられます（3 章・15 章）。

色が決まる順（後ほど強い）:

1. ブックのテーマ
2. ブックの設定の「文字の色」
3. 利用者の設定の「文字の色」

## 8. 箱・リスト・形・絵・データ

### 箱

「ボックスの追加」で次を決めて置きます。後から「ボックスの編集」で変えます。

- キャプションと、その寄せ（左・中央・右）
- 区切り線（キャプションと本文の間）
- 本文と、その寄せ・縦の位置（上・真ん中・下）
- テーマ（「ブックを継承」でブックのテーマに従う）
- 色

注: 選べるテーマは、ブックの設定で選べるテーマと同じです（3 章「ブックの設定」）。リストも同じです。

本文の幅を縮める:

1. 箱を選ぶ
2. 本文の端のつまみをドラッグする

- キャプションが中央寄せなら左右、左寄せなら右だけ、右寄せなら左だけ動かせます
- キャプションの幅より狭くはなりません。区切り線も一緒に縮みます

### リスト

行を並べるアイテムです。「リストの追加」「リストの編集」で次を決めます。

- キャプション・区切り線・本文・テーマ・色
- チェックリストにする。外すと、チェックの状態が消えます
- 行を交互に色分け
- 行の高さ: 「中身が見える高さにそろえる」「最大行にそろえる」、または行数で決める
- チェック済みを: グレーアウトする、並べ替える（なし・先頭・最後）

行を選ぶ:

- 行を押す: その行だけを選びます。行に選択の枠が付きます
- 見出しを押す: リストを選びます
- Mod+クリック: 同じリストの行を選択に足します。選んでいる行なら外します
- Delete・Backspace: 選んでいる行を全部消します

注: 行を選んだまま、ほかのアイテムを Mod+クリックすると、行の代わりにそのリストが選ばれます。

行の操作:

- 行の追加・行の編集・行を削除（行の右クリックで、行の編集・行を削除）。右クリックの「行を削除」は、押した行だけを消します
- 行をチェックする: チェックリストにすると、各行の左にチェックの枠が出ます。押すと入れ切りできます
- 行を動かす: 行を押して少し動かすと、ドラッグになります。同じリストの中か、同じページのほかのリストへ動かせます。落とす所の行の間に線が出ます
- 行の高さを変える: 行の下の端をドラッグします。1 行ずつ変わります

注: チェックリストでないリストへ動かした行は、チェックが外れます。

チェック済みを先頭か最後に並べ替えているリストでは、行を落とせる所が分かれます。

- チェックの無い行は、チェックの無い行の間にだけ落とせます
- チェック済みの行（ほかのリストから持ってきたもの）は、チェック済みの行の間にだけ落とせます
- ポインタがその並びの外へ出ても、線はその並びの端で止まります。そこで離すと、並びの端に入ります
- 落とした行は、そのあと並べ替え直されても、同じ並びの行との順のまま出ます

注: このリストのチェック済みの行は、ドラッグできません。

### 形（フローチャートだけ）

「形の追加」で形を選んで置きます: 角丸・箱・ひし形・平行四辺形・平行四辺形（逆）・台形・台形（逆）・六角形・円。キャプションと寄せ、色を決められます。

台形と台形（逆）は、ダイアログの「90 度回転」で横向きにできます。流れの向きが「右へ」のページでは、初めから回った向きです。

### 絵

「絵の追加」で絵を選んで置きます: スティックマン・DB・サーバー・パソコン・工場・書類・ゴミ箱・ロボット・猫・ハート・電球・犬・森・家・家族（15 種）。キャプションと色を決められます。

形と絵は、ツールボックスの「形」のボタンで開く格子から選びます。

### データ（図面だけ）

表を持ち、表かグラフで見せるアイテムです。

置く:

1. ツールボックスの「データ」を押す
2. 紙の上で置きたい所を押す

置いたばかりのデータは、点線の枠に「No Data」と出ます。

表を書く:

1. データをダブルクリックして、「データの編集」を開く
2. 「＋ 列を足す」で列を足す。列ごとに名前と型（数・文字）を決める
3. 「＋ 行を足す」で行を足し、セルを書く
4. 「確定」を押す

注: 紙に収まらないと、ダイアログは閉じずに「紙に収まりません」と出ます。

- 列や行の × で消します
- 列を全部消して確定すると、「No Data」に戻ります
- 表で見せている間は、表が全部見える大きさに合わせます（紙の端まで）。周りのアイテムが動けず広がれないときは、大きさはそのままで、入りきらない所は表の中でスクロールします
- 箱と同じく、データからも線を引けます

注: 行は列を 1 つ以上足してから足せます。
注: 数の列のセルは空にできません。数が無い所には 0 を書きます。
注: 数の列に数でない文字を書くと、そのセルが赤くなり、「確定」を押せません。
注: 文字の列を数の列にできるのは、どのセルも数として読めるときだけです。読めないと「数でないセルがあります」と出ます。

見た目を選ぶ:

ダイアログの「見た目」で、表・棒グラフ・折れ線グラフ・円グラフ・散布図から選びます。グラフでは、どの列を使うかを選びます。

- 棒・折れ線: 「横軸」の列と、「値」の列（いくつでも）
- 円: 「ラベル」の列と、「値」の列（1 つ）
- 散布図: 「X」「Y」の列（どちらも数の列）と、「点のラベル」の列（なしでもよい）

見た目を変えたとき、値の列がまだ選ばれていなければ、使う列が先に選ばれます。値の列は 8 つまでです。使う列が選ばれていない・合わない（散布図の X が数の列でないなど）と、「確定」を押せません。

グラフごとの項目:

- 向き（棒）: 縦・横
- 並べ方（棒・円）: 表の順・多い順・少ない順。棒で多い順・少ない順にし、値の列が 2 つ以上なら、「並べる値」で並べる元の列を選びます
- 入りきらない文字（縦の棒・折れ線）: 間を飛ばす・傾ける
- 出す文字（棒・折れ線）: 等間隔・多い順・選んだ行だけ

「選んだ行だけ」にすると、表の各行に「文字を出す」の印が出ます。印を付けた行の項目の文字だけが出ます。

注: 傾けても入らないときは、間も飛ばします。
注: 棒・折れ線で値の列が 2 つ以上なら、凡例が出ます。円グラフはいつも凡例が出ます。
注: 棒・点・円の切れ端にポインタを乗せると、値が出ます。
注: 円グラフは、9 つ以上の切れ端を「その他」にまとめます。負の値があると「負の値は円にできません」、どれも 0 なら「値がどれも 0 です」と出て、描かれません。

キャプションと本文:

箱と同じく、キャプション・区切り線・本文と、その寄せを書けます。「文字の置き場所」で、表やグラフの上・下・出さないを選びます。

つまみで直す（データを選んでいる間）:

- 項目の文字の領域: 縦のグラフでは文字の領域の上の端、横の棒では右の端をドラッグして、広げ縮めします
- 本文の幅: 本文の端のつまみをドラッグします（箱と同じ）

グラフの動き:

グラフは、初めて描いたとき・表を入れ替えたとき・見た目や使う列を変えたときに動きます（棒が伸びる、折れ線が引かれるなど）。大きさを変える・選ぶ・つまみを動かすときは動きません。

注: OS で「動きを減らす」設定にしていると、動きません。
注: 色や動き方はテーマで決まります。

## 9. 線

### 線を引く

1. 選択ツールで、箱（リスト・形・絵も）にポインタを乗せる
2. 四辺の外に〇が出る。〇を押して、相手のアイテムまでドラッグする
3. 相手の上で離す

- 何も無い所で離すか、Escape で、引くのをやめます
- 同じアイテムへ戻る線も引けます
- 引いた後にダイアログは出ません

### 線を編集する

線のダブルクリックか、右クリックの「設定」で「線の編集」を開きます。

- 通り方: 折れ線・直線
- 線の種類: 実線・破線
- 始点の形・終点の形: なし・塗りの三角・開いた矢じり・白抜きの三角・塗りのひし形・白抜きのひし形、ER 図の記号（1・多・0 か 1・0 以上・1 以上）
- キャプション: 「候補」のボタンが出るときは、押すとキャプションに入ります（例: フローチャートのひし形から出る線の Yes・No）
- 端の位置: 次のボタンを押してから「確定」します
  - 整列: 両端を辺の真ん中に固定します。向き合う辺どうしでまっすぐ結べるなら、まっすぐ結ぶ位置にします
  - 接辺の自動選択: 端の固定をやめ、つなぐ辺と位置を自動で選びます
  - 折れ線を自動に戻す: 動かした途中の区間をやめ、自動の形に戻します
  - キャプションの位置を自動に戻す
- 線を消す

### 線をじかに直す

線を押して 1 本だけ選ぶと、両端に丸が出ます。

- 端を固定する: 端の丸をドラッグして、箱のふちで離します。ほかの線の端に近づくと、吸い付きます
- つなぎ替える: 端の丸をドラッグして、ほかの箱の上で離します
- 途中の区間を動かす: 折れ線の途中の区間をドラッグすると、左右か上下に動きます
- キャプションを動かす: キャプションの札をドラッグします

Escape で取りやめます。

### 線の既定の通り方

図面とフローチャートで、ブックの設定とページの設定で決めます。ページで「ブック継承」を選ぶと、ブックの設定に従います。

注: 線で結んだアイテムどうしは、少し広めに間を空けます。

## 10. ブックのタイプ

### 図面

箱・リスト・絵・データ・線を、紙の上に自由に置くブックです。ツールボックスには「箱」「リスト」「データ」「形」があり、「形」の格子には絵が並びます。形（角丸など）はありません。

スクラップも置けます（20 章）。

### フローチャート

形と線で流れを書くブックです。ツールボックスには「箱」「形」があり、「形」の格子には形と絵が並びます。リストはありません。箱は図面の箱と同じですが、中に物を入れられません。

スクラップも置けます（20 章）。

流れの向き: 下へ・右へ。ページごとに決めるか「ブック継承」。

#### 自動で整列

1. 紙の何も無い所を右クリックし、「自動で整列」を押す
2. 「レイアウトを自動で整えてもよいですか？」と出る。「実行」を押す

- 始まりの形から、本筋を紙の真ん中に並べ、分岐は横に出します
- 線の固定した端や、手で動かした通り方は外れます
- 紙に収まらなければ「紙に収まりません」と出て、何も変わりません
- 可変ページでは、紙 1 枚の幅で折り返して並べ、下へはいくらでも続けます。収まらなくても断らず、印刷区画を足します
- 台形などがあると、確かめに「（形の名前）をページに合わせて整列」の切り替えが出ます。初めはオフです。オンにすると、形の向きもページに合わせます

### ツリー

節を枝分かれでつなぐブックです。新しいブックを作るとき、「ツリーの設定」で伸びる向き（上へ・下へ・左へ・右へ・中央から）を決めます。

編集ツールでの操作:

- 押した節を選びます。選んだ節は真ん中に来ます
- 選んだ節のまわりに小さな点が出ます。ポインタを近づけると＋の丸に開きます: 子を足す・前に兄弟を足す・後ろに兄弟を足す。押すと空の節を足し、その場で書き始めます
  - 根には兄弟の＋はありません
  - 伸びる向きが「中央から」のツリーの根では、上に子を足す・下に子を足す・左に子を足す・右に子を足すの 4 つです
- ダブルクリックで、その場でキャプションを書き始めます。根だけは、ページの設定が開きます
- 根でない節をドラッグで移します。節の真ん中に落とすと、その子の末尾に入ります。端の近くに落とすと、前か後ろの兄弟になります
- 右クリックでその節を選び、メニューが開きます: キャプションを書く・節の色・節の大きさ・削除・AIに伝言・AIに示す

キー（編集ツールのとき）:

- 子を足す（Tab）
- 後ろに兄弟を足す（Enter）
- キャプションを書く（F2）
- 節を消す（Delete・Backspace）: 子孫ごと消えます。根は消せません
- 選ぶ節を替える（矢印キー）: 伸びる向きで最初の子、逆で親、横で隣の兄弟
- 根を選ぶ（Home）

前に兄弟を足すのは、＋からだけです。その場で書いている間は、Enter で確定、Escape で取り消します。

節の見た目:

- 節の形: 箱・下線
- 節の色
- 節の大きさ: 伸びる・字数で折り返す・字数で固定
- 線の形: 直線・折れ線・曲線

#### 節の色

1. 節を右クリックし、メニューの「節の色」を押す
2. その節のすぐ下に、色のパネルが出る
3. 色を選ぶ
   - テーマの色 1〜6・「なし」: 押すとすぐ塗り、パネルが閉じます
   - 好きな色: 押すと色を選ぶポップアップが開きます（7 章「色を選ぶ」）。選んだ色は、パネルの外を押して閉じたときに塗ります
4. パネルの外を押すか Escape で閉じる（Escape は、好きな色で選んだ色を塗らずに閉じます）

- 拡大・縮小やスクロールをしても、パネルは節に付いてきます。パネルの大きさは変わりません
- 根の色も同じように変えられます

注: ロック中は色を押せません。

ページの設定（紙の右クリックか、根のダブルクリック）:

- ページ名
- 根のキャプション
- 根の本文（上に装飾のボックスが出ます）
- 本文を紙に描く: 根の本文を、根の箱の中に描きます。根のキャプションの下に区切りを挟んで描き、根の箱が大きくなります
- 紙のサイズ・向き・可変ページにする（4 章「可変ページ」）
- 伸びる向き・節の大きさ・節の形・線の形の既定（「ブックを継承」でブックの設定に従います）
- ページを削除
- 見出しの右の鍵: ページをロックする・ロックを外す（押してから「確定」）

ロック中のページの設定:

- 項目を変えられません。鍵を外す方にすると変えられます
- 「ページを削除」は押せません

### ディレクトリ構成図

フォルダとファイルの構成を書くブックです。ページを作るとき、根のフォルダの名前を決めます。

鉛筆での操作:

- 押した行を選びます
- ＋でフォルダとファイルを足します
- ダブルクリックで、その場で名前を書き始めます。説明を表示しているページでは、説明の列のダブルクリックで説明を書けます
- 根でない行をドラッグで移します。フォルダの真ん中に落とすと、その中に入ります。行の上下の端に落とすと、その前か後ろに入ります。ファイルは上半分で前、下半分で後ろです
- 右クリックでその行を選び、メニューが開きます: 設定…・昇順で並べる・降順で並べる・削除・AIに伝言・AIに示す

▸・▾ を押すと、フォルダを開け閉めします。ハンドツールのときもできます。

キー（鉛筆のとき）:

- 選ぶ行を替える（↑・↓）
- フォルダを開く（→）、閉じるか親を選ぶ（←）
- 根を選ぶ（Home）
- 名前を変える（Enter・F2）
- 下にフォルダを足す（D）、下にファイルを足す（F）。修飾キーを付けると効きません
- 中に足す（Tab）: フォルダを選んで押すと、行のすぐ右に「フォルダ」「ファイル」の小さな枠が出ます。↑・↓ で選び、Enter か押すと、フォルダの中の末尾に足して名前を書き始めます。Escape でやめます
- 削除（Delete・Backspace）

ほかの操作:

- 昇順で並べる・降順で並べる: フォルダの直下を名前で 1 回並べます。フォルダが先です
- 「設定…」でノードの設定を開き、名前・説明・色を変えます
- 説明の見せ方: 説明を表示、説明の前に「・・・」、説明の左に区切り線

可変ページ（ページの設定でオン）では、行は下へ、説明は右へいくらでも続きます。説明は切らずに 1 行で描きます。

### マークダウン

Markdown で文書を書くブックです。1 ページが 1 つの文書です。紙は無く、アイテムもツールもありません。

ページを足す:

1. 下の行の＋を押す（ページが無ければ、真ん中の「ページを作る」）
2. 「新しいページ」のダイアログで、ページの名前と紙のサイズ・向きを決める
3. 「作成」を押す

- 紙のサイズ・向きは、印刷するときの紙です。書く画面には紙が出ません

ペイン:

画面は 2 つのペインに分かれます。

- ソースのペイン: Markdown の文書を書く所です
- プレビューのペイン: 書いた文書を描いた所です。ソースのペインに書くと、すぐ描き直します

初めの並べ方:

並べ方をまだ選んでいなければ、ページを開いたときに、本文から並べ方を決めます。

| 開いたページ | 並べ方 |
|---|---|
| 本文がある | プレビューだけ |
| 本文が空 | 左右に並べる（左にソース、右にプレビュー） |

- 決めるのは、ページを開いたとき（ページのタブで替えたとき）の 1 回だけです
- 空のページに書き始めても、左右のままです。画面を読み直すか、ページを開き直すと、プレビューだけになります
- 並べ方を一度選ぶと、そのステージでは、どのページも選んだ並べ方で開きます（下の「並べ方を覚える」）

注: 空白や改行だけの本文は、空と見ます。

並べ方を変える:

ペインの上に、いつも 1 本の行（上の行）が出ます。上の行の右端の 4 つのボタンで、並べ方を選びます。ボタンは絵だけで、ポインタを乗せると名前が出ます。

| ボタン | 並べ方 |
|---|---|
| ソースだけ（鉛筆の絵） | ソースのペインだけを出します |
| 左右に並べる（縦に分けた枠の絵） | 左にソースのペイン、右にプレビューのペイン |
| 上下に並べる（横に分けた枠の絵） | 上にプレビューのペイン、下にソースのペイン |
| プレビューだけ（目の絵） | プレビューのペインだけを出します |

- 今の並べ方のボタンは、押した見た目になります
- 並べている間は、ペインごとに上に「ソース」「プレビュー」の見出しが出ます。見出しは、ページのタブのような見た目です。1 つだけのときは出ません
- 並べ方を変えても、入れ替えた順と、ペインの大きさはそのままです

注: 表の左右・上下は、ペインを入れ替えていないときの順です。入れ替えた後は、下の「ペインを入れ替える」のとおりです。

ペインを入れ替える:

1. 並べている間に、どちらかのペインの見出しを掴む
2. もう片方のペインの上まで動かす。離すと入れ替わるペインに、薄い色が重なる
3. 離すと、2 つのペインが入れ替わる

- ペインの外で離すと、入れ替えません
- 一度入れ替えると、その順を左右にも上下にも使います（左右で右にあるペインは、上下では下に来ます）
- 境目を動かしただけでは、入れ替えたことになりません。左右はソースが左、上下はプレビューが上のままです
- 入れ替えても、ソースのペインに書いている途中の字はそのままです

ペインの大きさを変える:

1. 並べている間に、2 つのペインの境目を掴む
2. 動かすと、ペインの大きさが変わる

- 境目をダブルクリックすると、半分ずつに戻ります
- どちらのペインも、全体の 15% より小さくなりません

並べ方を覚える:

並べ方・入れ替えた順・ペインの大きさは、ステージごとに覚えます。

- 覚えるのは、並べ方のボタンを押す・ペインを入れ替える・ペインの大きさを変える、のどれかをした後です。それまでは、ページを開くたびに初めの並べ方で開きます（上の「初めの並べ方」）
- 覚えた後は、そのステージで開くどのページにも、同じ並べ方を使います
- 画面を読み直しても、そのまま戻ります
- 並べ方を変えても、ブラウザの戻る・進むの 1 段にはなりません
- ブックには残りません

スクロール位置を覚える:

ページごとに、ソースのペインとプレビューのペインのスクロール位置を、別々に覚えます。

- 初めて開いたページは、先頭から出ます
- 一度開いたページは、ほかのページに替えて戻したとき、前回の位置で開きます
- 画面を読み直しても、前回の位置に戻ります
- 覚えるのは、最近スクロールした 30 ページまでです。それより前にスクロールしたページは、先頭から出ます

注: 位置は、並べ方と同じくステージごとに覚えます。ブックには残りません。

右クリックのメニュー:

上の行・ペインの見出し・プレビューのペインを右クリックすると、メニューが開きます。

- 画面を分割（2 章「画面を分割する」）
- ステージを閉じる
- スクラップを切り抜く（20 章）
- ページの設定（4 章「ページの設定」）
- ブックの設定（3 章「ブックの設定」）

注: 「画面を分割」は分割していないときだけ、「ステージを閉じる」は分割しているときだけ出ます。

注: ソースのペインの右クリックは、字の右クリックのメニュー（ブラウザのメニュー）のままです。

ソースのペインで書く:

- 両方を並べている間は、ソースのペインをスクロールすると、プレビューのペインが同じ所に付いてきます
- Tab キーで書く字は、設定画面の「マークダウン」の「Tabキー」で選びます（15 章）
- 続けて書いた字は、元に戻す 1 段にまとまります（11 章）
- ロック中は書けません
- AI が文書を書き換えると、書いている所はそのままで、ソースのペインの中身が替わります
- 文書の改行は、いつも同じ改行の字にそろいます。AI がほかの改行の字（Windows の改行など）で書いても、そろえて残ります

ソースのペインの印:

ソースのペインに、薄い印を出せます。出すかどうかは、設定画面の「マークダウン」で選びます（15 章「マークダウンの項目」）。

- 行番号: 左の列に、行の番号が出ます。初めから出ています
- カーソルのある行の下線: 書いている行の下に線が出ます。折り返した行では、最後の段の下に出ます
- 空白と Tab: 半角スペースは点、全角スペースは四角の枠、Tab は矢印で出ます

- 印は字ではありません。コピーした字には入りません
- カーソルのある行の下線は、ソースのペインで書いている間だけ出ます

プレビューのペインの見え方:

- 文書は紙の幅で描きます。ペインが紙より狭いときだけ、縮めて収めます
- リンク: http・https・mailto のリンクは、新しいタブで開きます。# で始まるリンクは、同じ文書の見出しや脚注へ飛びます。ほかのリンクは開きません
- 画像: 文書に埋め込んだ画像だけを描きます。外の画像は読み込みません
- HTML は、そのまま字として出します（下の「コードの色付け」のとおり色が付きます）

コードの色付け:

コードの塊の始めの ``` の後に言語名を書くと、プレビューのペインで、キーワード・文字列・コメントなどを色分けして描きます。

````
```ts
const a = "s"
```
````

- 言語名は別名でも書けます（ts・js・sh・py・yml など）。大文字と小文字は問いません
- 言語名が無いときと、知らない言語名のときは、色を付けません
- 文書の中にじかに書いた HTML のブロックは、言語名が無くても HTML として色を付けます
- 文中のコード（`` `…` `` で囲んだ所）には、色を付けません
- 色は字の色だけです。太字や斜体にはしません
- 印刷プレビューと印刷にも同じ色が付きます
- ソースのペインには、色は付きません
- 色はブックのテーマで変わります（下の「テーマ」）

色を付けられる言語の例: C・C++・C#・Go・Java・JavaScript・TypeScript・Kotlin・Swift・Rust・Zig・Python・Ruby・PHP・Perl・Lua・R・SQL・Bash・HTML・XML・CSS・SCSS・Sass・Less・JSON・YAML・INI・Makefile・Markdown・diff など

注: diff は、足した行と消した行を別の色で描きます。

テーマ:

ブックの設定のテーマで、「標準」か「GitHub 風」を選びます（3 章「ブックの設定」）。

- GitHub 風: GitHub の Markdown に似せた見た目です。字の大きさ・見出しの下線・表・コード・リンクの見た目が GitHub に似ます
- GitHub 風は、明るい見た目と暗い見た目を持ちます。OS の明暗に合わせて切り替わります
- コードの色: 標準は、明るい紙に合う色です。GitHub 風は、明るい見た目と暗い見た目それぞれの GitHub に近い色です

注: 付箋紙・シンプル・matomezu は、マークダウンのブックでは選べません。前に付箋紙などを当てていたマークダウンのブックは、標準で描き、ブックの設定のテーマの欄も「標準」になります（当てていた値は、データに残ります）。図面の箱やリストに、そのブックで選べないテーマが前から当たっていたときも同じで、ブックのテーマで描きます。

段落の中の改行:

ソースのペインで、段落の中で 1 回だけ改行した所の見せ方を選べます。設定画面の「マークダウン」の「段落の中の改行」で選びます（15 章「マークダウンの項目」）。

- 改行にする（既定）: 書いたとおりに改行して描きます
- 空白にする（GFM方式）: 改行せず、空白を 1 つ挟んで前の行に続けて描きます（日本語の文の途中にも空きが入ります）

- プレビューのペインと、印刷プレビュー・印刷に効きます
- ソースのペインの文書は変わりません。AI が読む文書も、書いたとおりのままです
- 利用者の設定なので、見る人ごとに見え方が変わります

注: 行の末に半角スペースを 2 つか、`\` を書いて改行した所は、どちらを選んでもいつも改行になります。

印刷で紙に切る（12 章）:

- 紙の高さで、ブロック（段落・見出し・表など）の境目で切ります
- 見出しは、次のブロックと同じ紙に入れます
- 長い段落・リスト・コード・表は、行の間で切って次の紙に続けます。表は行ごとに切ります
- 画像は、紙の残りに半分以上入るなら、縮めて今の紙に入れます。入らなければ次の紙へ送ります
- 紙より高い画像は、紙の高さに縮めます
- 紙の幅に入らないブロックは、幅に合わせて縮めます
- 文書が空のページは、印刷しません

#### 検索と置換

検索ダイアログで、文書の中の字を探して、置き換えます。探せるのは、マークダウンのブックです。

検索ダイアログを開く:

ブックを開いたステージで、キーを押します。ソースのペインに書いている途中でも開けます。

| キー | 開き方 |
|---|---|
| Mod+F | ページ内を検索（範囲が「このページ」） |
| Mod+Shift+F | ブック内を検索（範囲が「ブック全体」） |
| Mod+Alt+F | 検索して置換（「置換」の入力Formから書く） |

- ダイアログは、初めは画面の右上に出ます
- 見出しの「検索」を掴んで動かせます。動かした所は、閉じて開き直しても同じです。画面を読み直すと、右上に戻ります
- 開いたまま、ほかの操作ができます（ソースのペインに書く・スクロールするなど）。ダイアログの外を押しても閉じません

注: キーは、設定画面のショートカットキーで変えられます（15 章「ショートカットキーを変える」）。

検索ダイアログの作り:

| 所 | 使い方 |
|---|---|
| 探す | 探す字を書きます。右に当たりの数が出ます |
| 置換 | 置き換える字を書きます |
| ↑ 前へ・↓ 次へ | 前の当たり・次の当たりへ移ります |
| 1 つ置換 | 今の当たりを置き換えて、次の当たりへ移ります |
| 全部置換 | 範囲の当たりを全部置き換えます |
| 大文字小文字を区別 | 入れると、大文字と小文字を別の字として探します |
| 正規表現 | 入れると、「探す」の字を正規表現として読みます（下の「正規表現で探す」） |
| 範囲 | 「このページ」か「ブック全体」を選びます |
| 端まで行ったら反対の端から続ける | 入れると、最後の当たりの次は最初の当たりへ戻ります。外すと、端で止まります。初めは入っています |

探す:

1. 「探す」に字を書く
2. 当たりが、ソースのペインとプレビューのペインの両方で光る。今の当たりは濃く光る
3. 「探す」の右に、何番目の当たりか・当たりの数が出る（例: 3/12）

- 範囲が「ブック全体」なら、今の当たりが何ページ目か・ページの数も出ます（例: 3/12（2 / 5））
- 字や切り替えを変えると、今の当たりの所から先の、最初の当たりが今の当たりになります

当たりを移る:

| キー | 動き |
|---|---|
| Enter・F3 | 次の当たりへ |
| Shift+Enter・Shift+F3 | 前の当たりへ |

- ボタンの「↓ 次へ」「↑ 前へ」でも移ります
- Enter・Shift+Enter は、ダイアログの入力Formの中で効きます。F3・Shift+F3 は、ソースのペインに書いている間も効きます
- 範囲が「ブック全体」なら、当たりのある次のページを開いて移ります

正規表現で探す:

- ^ と $ は、行の頭と行の末に当たります
- \n で、行をまたいで探せます
- 「置換」の字に $1 などを書くと、( ) で囲んだ所の字に置き換わります
- 正規表現として読めない字なら、「探す」が赤くなり、数は 0/0 です

置き換える:

1. 「置換」に置き換える字を書く（Mod+Alt+F で開くと、ここから書けます）
2. 「1 つ置換」か「全部置換」を押す

- 1 つ置換: 今の当たりを替えて、替えた字の後ろの次の当たりへ移ります
- 全部置換: 範囲の当たりを全部替えます。範囲が「ブック全体」なら、全部のページを替えます
- 全部置換は、元に戻す 1 回で全部戻ります（11 章）
- 当たりが無いときは、どちらも押せません
- ロック中は、どちらも押せません

注: 範囲が「ブック全体」の全部置換は、ロック中のページが 1 つでもあると押せません。

閉じる:

- 見出しの × か、ダイアログの入力Formの中で Esc を押して閉じます
- 閉じると、今の当たりの字を、ソースのペインで選んだ状態になります。そのまま書くと、選んだ字が書いた字に替わります
- 閉じると、光りも消えます

### スライド

1 ページが 1 枚のスライドになるブックです。紙は初め「スライド用(16:9)」の横です。文字枠・自由な線・直線・楕円を、紙の上に自由に描きます。

ページは、ステージの左のページ一覧で開く・並べ替える・足す・複製する・削除します（4 章「ページ一覧」）。ページのタブは出ません。

ツールボックスに並ぶ物:

- 文字枠
- 自由な線
- 直線
- 楕円

注: 箱・リスト・形・絵・データ・線は置けません。

スライドの物は、図面の物と次の所が違います。

- 近くの物を押しのけません。重ねて置けます
- 紙からはみ出して置けます。はみ出た所は見えません。印刷でも切れます
- 後から置いた物が、上に重なります。重なり順は後から変えられます（下の「重なり順」）
- 線でつなげません

#### 置く

1. フッタメニューのツールボックスで、置く物を押す
2. 紙の上でドラッグする。ドラッグしている間も、置く物（楕円なら置いたときと同じ楕円）が見え、ドラッグした四角に置かれる。楕円は、Ctrl（Mac は Command）を押しながらドラッグすると、正円になる
3. 置いた物が選ばれる

- 直線は、ドラッグの始めから終わりまでの線になります
- 自由な線は、なぞった跡の線になります
- ドラッグせずに押すだけなら、押した所に決まった大きさで置きます
- 押しただけで置く文字枠は、高さが文字 1 行分、幅は 1 文字より狭い（カーソルが 3 つ並ぶくらい）です。文字を打つと文字の幅に寄ります
- 文字枠は、置くとそのまま文字を打てます。外を押すと決まります
- 文字を書かずに外を押す（Escape でやめる）と、文字枠は何も言わずに消えます
- 文字枠は、書いている文字の幅と高さに寄ります。1 行が長くなると幅が、改行して行が増えると高さが広がり、文字を減らすと縮みます（左上の角は動きません）。枠を狭くして折り返すようにした枠は、幅を変えず、高さだけが文字に寄ります

注: 文字枠を置いて続けて打った文字は、元に戻すの 1 段にまとまります。

#### 選ぶ・動かす

- 押すと、その 1 つを選びます
- ドラッグで動かします
- 何も無い所を押すと、選択を外します

いくつかを一緒に選ぶ:

- 範囲で選ぶ: 何も無い所からドラッグすると、四角が出ます。四角に少しでもかかった物を選びます
- Shift か Mod を押しながら押す: 押した物を選択に足します。選んでいる物なら、選択から外します
- Shift か Mod を押しながら範囲で選ぶと、前の選択に足します

Mod は 7 章「選ぶ」と同じです（Windows・Linux では Ctrl、Mac では ⌘）。

いくつか選んでいるとき:

- 選んだ物の全体を、点線の枠が囲みます
- 選んだ物のどれかか、点線の枠の縁をドラッグすると、全部を一緒に動かします
- 一緒に動かしたのは、元に戻すの 1 回で戻ります
- 選んだ物の 1 つを押して、動かさずに離すと、その 1 つだけの選択になります
- 大きさを変えるつまみと、回すつまみは出ません
- バーには、色などの道具だけが出ます。角度は出ません（下の「バー」）

#### 大きさを変える

選ぶと、四隅と四辺につまみが出ます。つまみをドラッグします。

- 角のつまみ: 縦と横を一緒に変えます。文字枠では、文字も一緒に大きくなります。楕円では、Ctrl（Mac は Command）を押しながら引くと、正円のまま変わります
- 辺のつまみ: 幅か高さだけを変えます。文字枠の文字の大きさは変わらず、折り返しが変わります

注: 1 つだけ選んでいるときに出ます。
注: 直線の端がある角では、角のつまみの上に、線の点の丸いつまみが重なります。そこを押すと点を動かします（下の「線の点を動かす」）。

#### 回す

選んだ物の右上の角の、斜め外のつまみをドラッグします。

- Shift を押しながらなら、15 度ずつ回ります
- 角度は、直線・自由な線なら、選んだ物の上に出るバーで、数字でも入れられます。文字枠と楕円は、バーの「水平に戻す」で角度を 0 に戻せます（下の「バー」）

注: 1 つだけ選んでいるときに出ます。

#### バー

選んだ物の上に、小さなバーが出ます。上に場所が無ければ下に出ます。

1 つだけ選んでいるときの、どの物にも出る道具:

- 角度（文字枠・楕円以外）: 数字を入れて Enter（か外へ出る）で回します。0 で水平に戻ります。数字でなければ元の値に戻ります
- 水平に戻す（文字枠と楕円だけ。角度の入力の代わり）: 回して角度が付くと押せるようになり、押すと角度が 0（真正面）に戻ります。角度が 0 のときは押せません

その後ろに、選んだ物の種類に合う見た目の道具が並びます。

| 選んだ物 | 並ぶ道具 |
|---|---|
| 文字枠 | 文字色 |
| 自由な線 | 色・太さ・点線 |
| 直線 | 色・太さ・点線・矢印 |
| 楕円 | 塗り・枠の色・太さ |

- 色の道具（文字色・色・塗り・枠の色）: 押すとポップアップが開きます。見本の色を選ぶか、色の値（#rrggbb）を入れます（7 章「色を選ぶ」）
- 太さ: 数字を入れて Enter（か外へ出る）で決まります。数字でなければ元の値に戻ります
- 点線: 押すと点線になります。もう一度押すと実線に戻ります
- 矢印: 押すと、線の終わりの端に矢印が付きます。もう一度押すと外れます

注: 楕円の太さは、枠の太さです。0 にすると枠が無くなります。
注: スライドの色の「なし」は、文字色・色ではテーマの文字の色、塗りでは塗らない、枠の色では枠を描かない、です。枠の色を決めていない楕円は、テーマの文字の色で枠が描かれます。AI は、枠の色に "none" を入れて枠なしにできます
注: 線の終わりの端は、直線を置いたときに引き終えた側です。

いくつか選んでいるとき:

- 見た目の道具が、選んだ物の全部に一度に効きます
- 出るのは、選んだ物のどの種類にもある道具だけです。たとえば直線と自由な線なら、色・太さ・点線です。文字枠と楕円のようにどの種類にも共通の道具が無い組み合わせでは、バーは出ません
- 道具に出る今の値は、選んだ物のうちの 1 つのものです

#### 重なり順

選んだ物を右クリックして、メニューから選びます。

| 項目 | すること |
|---|---|
| 最前面へ | いちばん上に重ねます |
| 1 つ前へ | 1 つ上に重ねます |
| 1 つ後ろへ | 1 つ下に重ねます |
| 最背面へ | いちばん下に重ねます |
| 消す | 消します（下の「消す」） |

キーでも変えられます。

| キー | すること |
|---|---|
| Mod+Alt+] | 1 つ前へ |
| Mod+Alt+[ | 1 つ後ろへ |
| Mod+Alt+Shift+] | 最前面へ |
| Mod+Alt+Shift+[ | 最背面へ |

- 選んでいない物を右クリックすると、その物だけを選んでメニューを開きます
- いくつか選んでいれば、選んでいる物の全部に効きます。選んだ物どうしの前後は変わりません
- 元に戻すの 1 回で戻ります

注: ブラウザの「戻る・進む」「タブの切り替え」と重ならないよう、Alt も押すキーにしています。キーは設定画面で変えられます。範囲「スライド」にあります（15 章「ショートカットキーを変える」）。

#### 線の点を動かす

直線か自由な線を 1 つだけ選ぶと、線の点に丸いつまみが出ます。

- 直線: 両端に出ます
- 自由な線: 線の点の全部に出ます

1. 丸いつまみをドラッグする
2. 離すと、点がそこに動きます。線を囲む枠も合わせて変わります

- Shift を押しながらなら、となりの点から見て 45 度ずつの向きにそろいます。真横・真縦にもできます
- 線を選んでいるときは、枠の大きさを変える 8 つのつまみは出ません（形は丸いつまみで変えます）
- 点を動かすと、線の角度は 0 に戻ります
- 元に戻すの 1 回で戻ります

注: 点の多い自由な線では、丸いつまみは間引いて出ます。始めと終わりの点には必ず出ます。

#### 文字を書き換える

1. 書き終えた文字枠をダブルクリックする（中にカーソルが入ります）
2. 文字を書く
3. 外を押すと決まります。Escape でやめます。全部消して終えると、文字枠ごと消えます（元に戻すで戻せます）

#### 消す

選んで Delete か Backspace を押します。右クリックのメニューの「消す」でも消せます。

- いくつか選んでいれば、選んでいる物を全部消します
- 元に戻すで戻せます

#### スライドの印刷

印刷プレビューには、1 ページが紙 1 枚で並びます。紙からはみ出た所は切れて刷ります。

何も描いていないスライドを出すかは、設定の「スライドの印刷」で決めます。ブックの設定と、ページの設定の両方にあります。

| 選べる物 | 印刷プレビューに |
|---|---|
| 中身があれば（既定） | 紙に掛かる物が 1 つでもあれば出します |
| 必ず | 何も無くても出します |
| 出さない | 出しません |

【未確定】ページの設定で選べる「ブック継承」に当たる選択肢の名前。

#### まだできない事

- 文字の大きさを数字で決める（角のつまみで大きさを変えると、文字も合わせて変わります。AI には頼めます。16 章）
- 文字枠の文字の揃え
- いくつか選んだ物を、まとめて大きくする・回す

### 背景（図面・フローチャート・ツリー・ディレクトリ構成図）

図面・フローチャート・ツリー・ディレクトリ構成図のページには、中身の下に敷く「背景」を描けます。背景に置けるのは、スライドと同じ文字枠・自由な線・直線・楕円です。

ふだんの背景:

- 中身（箱や線）の下に見えます。押しても選べません
- ミニマップには出ません
- 可変ページにして、左や上へ増やしても、背景は中身と同じだけずれて、中身に対する位置を保ちます（図面・フローチャート・ツリー・ディレクトリ構成図）

背景を編集する（背景編集モード）:

1. 次のどちらかで入ります
   - 下の行のブックの名前にマウスを乗せて上がるフッタメニューの「背景を編集」ボタン
   - ページのタブの右クリックのメニューの「背景を編集」（開いていないページなら、そのページが開きます）
2. 上に「背景を編集中」の帯が出ます。帯には「終了」と「コンテンツを隠す」があります
3. ツールボックスが、文字枠・自由な線・直線・楕円だけに替わります。置き方・選び方・動かし方は、スライドと同じです（10 章「スライド」）
4. 終わるときは、帯の「終了」・フッタの「背景を編集」をもう一度押す・Esc（何も置こうとしていないとき）のどれかです。ツールボックスは元に戻ります

背景編集モードの間:

- 中身は薄くなり、押しても選べません。「コンテンツを隠す」を押している間は、中身を描きません（データは変わりません。モードを出ると戻ります）
- ページのタブは出ません。ほかのページへは替えられません（ブックの名前と、フッタメニューは出ます）
- 拡大縮小・ステージの分割・ミニマップは、そのまま使えます
- 印刷プレビューを開いて閉じても、背景編集モードのままです
- 入る・出るときに、選んでいる物と、置こうとしている物は外れます
- ツリーでは、入るときに節のフォーカス（選んだ節が真ん中に来て、ほかが暗くなる動き）が外れ、ページ全体が収まります。出てもフォーカスは外れたままで、画面の位置は変わりません。節をクリックすると、フォーカスが戻ります

背景を印刷する:

- 印刷プレビューと印刷には、背景が中身の下に敷かれて出ます
- ふだん（自動）は、中身の載った印刷区画にだけ背景が出ます。背景だけで中身の無い印刷区画は、並びません
- 背景編集モードのフッタに「背景の印刷」の 3 つのボタン（中身があれば・必ず・出さない）が出ます。ページごとの設定です
  - 必ず: 中身が無くても、そのページを印刷に出し、背景を敷きます
  - 出さない: 中身があっても、背景は出ません
- ページの設定のダイアログと、ブックの設定にも「背景の印刷」があります。ページはブックを継承できます

AI から:

- AI がページを読むと、背景は「あるかどうか」と「文字枠の字」だけが見えます（形の位置・大きさ・種類は見えません）
- AI は、スライドと同じアクション（スライドに置く・動かす・項目を変えるなど）で背景を直せます

注: マークダウンには、背景はありません。

## 11. 元に戻す・やり直す

フッタメニューのボタンか、キーで操作します。

- 元に戻す（Mod+Z）
- やり直す（Mod+Shift+Z・Mod+Y）

Mod は、Windows・Linux では Ctrl、Mac では ⌘ です。画面のキーの表記も同じです。

- その窓で自分がした操作が戻ります。分割したもう一方のステージの操作も戻ります
- AI の変更と、別の窓やタブでした操作は、画面に見えたものだけが戻ります（下の「AI やほかの窓の変更」）
- ダイアログの確定 1 回、ドラッグ 1 回で 1 段です。ブックごとに 100 段まで戻せます
- ロックの掛け外しは戻りません
- 伝言とマークは戻りません。物を消して元に戻しても、その物に付いていた伝言とマークは戻りません（13 章）
- 戻せないときは「元に戻せません」、やり直せないときは「やり直せません」と出ます
- 印刷プレビューの設定の変更は戻りません。印刷プレビューの間は、元に戻す・やり直すは効きません（12 章）
- 変更提案郵便の反映は、1 段です。乗っていた変更が全部戻ります（14 章）

マークダウンのソースのペインで書いた字（10 章）:

- 続けて書いた字は 1 段です。次のときに段が切れます
  - 1 秒ほど手を止めた
  - 書く所を動かした
  - ソースのペインの外へ出た
- ソースのペインの中でも、元に戻す・やり直すのキーが効きます

注: 開いているブック全体がロック中なら、元に戻す・やり直すは薄くなって押せません。その操作で変えたページや、開いていないブックがロック中なら、押すと断られて、トーストに「元に戻せません」（やり直すは「やり直せません」）と出て、2 行目にどのブックが止めたか（「設計メモ」がロック中、など。名前の無いブックなら「関連ブックがロック中」）が出ます。どのブックも変わりません。入れているプラグインが止めているときも同じで、2 行目には、そのプラグインが止める理由に付けた名前が出ます。

### AI やほかの窓の変更

AI や別の窓・タブが変えた物は、画面に見えたときに、元に戻すの並びに入ります。入る所は、変えられた時刻の位置です。

見えたとするのは、次のときです。

- 図面・フローチャート: 変わった物の上の端が、画面の見えている所に入った
  - 箱の中の物なら、その物の上の端
  - 線なら、どちらかの端の物
  - 消えた物なら、消える前の場所
- ツリー・ディレクトリ構成図・マークダウン: そのページが画面に出た

注: 窓が裏のタブにある間は、見えたとしません。前に出たときに見えている物が、そこで並びに入ります。
注: 画面を分割して同じブックを出しているときは、どちらのステージで見えても、見えたとします。

元に戻すは新しい方から戻ります。

- 見えた AI の変更が自分の操作より後なら、AI の変更が先に戻ります
- 見えていない変更は、元に戻すで戻りません
- やり直すの残りは、よそからの変更が入っても消えません

戻すときは、自分が変えた所だけが戻ります。

- 物は、変えた項目だけが戻ります
- マークダウンの文書は、書いた行だけが戻ります
- その間に AI が別の所に書いた物は残ります

注: AI が同じ所を書いていたら、自分の元に戻すで上書きされます。

ロックの掛け外しや、別の窓での元に戻す・やり直すは、よそから来ても並びに入りません。

#### 見る前に AI の変更を消したとき

見る前に、自分の元に戻す・やり直すで AI の書いた物が消えることがあります（例: 自分で置いた箱のキャプションを、見えていない所で AI が書き換えた。そのまま元に戻すで、箱を置いたのを戻した）。

そのときは、次に AI に話しかけたとき、AI に「見られる前に消えた」と、消えた所と AI が書いた値が伝わります。AI は黙って書き直さず、要るなら利用者に聞きます。

注: 画面には何も出ません。

注: AI に伝わるのは、AI のフックで `matomezu annotations` を呼んでいるときです（13 章「AI とのやり取り」）。Claude Code は、matomezu のプラグインを入れていれば呼ばれます（16 章「Claude Code のプラグイン」）。

## 12. 印刷プレビューと印刷

ブックの全ページを、印刷する紙のとおりに並べて見せます。紙 1 枚に当たる 1 つを「印刷区画」と呼びます。可変ページでないページは、1 ページが 1 つの印刷区画です。

### 印刷プレビューを開く

- フッタメニューの「印刷プレビュー」を押す
- ブックを書いている間に Mod+P を押す（すぐには印刷せず、印刷プレビューを開きます）

開くと:

- ステージに、全ページの印刷区画が紙として並びます
- 右に右サイドパネルが開きます
- ページのタブとフッタメニューは隠れます
- 初めは、並べた紙の幅が画面に収まる倍率になります（横に並べているときは高さ）

注: ページを持つブックなら、どのタイプでも開けます。

印刷区画が並ばないもの:

- 何も載っていないページ（スライドは設定の「スライドの印刷」で変えられます。10 章「スライド」）
- 可変ページの、何も載っていない印刷区画（書く画面で薄く暗い印刷区画。4 章）

注: 並べる物が 1 つも無ければ、紙は並ばず「印刷できるものはありません」と出ます。

### 印刷プレビューで見る

印刷プレビューは見るだけです。物を選ぶ・置く・直すことはできません。元に戻す・やり直すも効きません。

- ホイールで紙をずらします
- ステージの右の端にスクロールバーが出ます。つまみをドラッグするか、溝を押して紙をずらします
- 紙が横に画面からはみ出すときは、下の端にもスクロールバーが出ます

### 右サイドパネル

上から次が並びます。

1. 見出し「印刷プレビュー」
2. 「印刷」のボタン（下の「印刷する」）
3. 拡大・縮小の帯（6 章）。「ページ全体を収める」の右に「幅に合わせる」が足されます（横に並べているときは「高さに合わせる」）
4. 「ブックをロックする」（ロック中は「ブックのロックを外す」）のスイッチ
5. 印刷プレビューの設定

印刷プレビューの設定:

| 項目 | 選べる物 | 既定 |
|---|---|---|
| 紙を並べる向き | 縦・横 | 縦 |
| 区画を数える順 | 横に進むのが先・縦に進むのが先 | 横に進むのが先 |
| ページ番号を入れる | オン・オフ | オフ |
| ブック名を入れる | オン・オフ | オフ |
| ページ名を入れる | オン・オフ | オフ |

- 「紙を並べる向き」: 縦は上から下へ、横は左から右へ並べます
- 「区画を数える順」: 可変ページの印刷区画を並べる順です。横に進むのが先なら、左から右へ進んでから次の段へ移ります。縦に進むのが先なら、上から下へ進んでから次の列へ移ります
- 「ページ番号を入れる」: 紙の下の真ん中に「1 / 5」のように入れます。番号は、並べた印刷区画全体の通し番号です
- 「ブック名を入れる」「ページ名を入れる」: 紙の左上に入れます。両方なら「ブック名 - ページ名」です

- 変えると、すぐに並べ直します
- 設定はブックに残ります。次に開いたときも同じです
- 変えても、元に戻すでは戻りません

ロック中のブックで設定を変える:

1. 項目を変える
2. 「ロック中ですが書き換えてもいいですか？」と出る
3. 「確定」を押すと変わります。ロックは掛かったままです。「キャンセル」なら変わりません

### 印刷プレビューを閉じる

- 右サイドパネルの閉じるボタンを押す
- Escape を押す
- 印刷区画をダブルクリックする: そのページの書く画面に戻ります

注: 印刷プレビューのまま画面を読み直すと、書く画面に戻ります。

### 印刷する

1. 印刷プレビューの「印刷」を押すか、印刷プレビューの間に Mod+P を押す
2. ブラウザの印刷ダイアログが開く
3. ブラウザの印刷ダイアログで印刷する

- 印刷区画 1 つを紙 1 枚に刷ります
- 印刷されるのは、印刷プレビューに並んだ紙だけです

注: 印刷区画を数えている間と、並べる物が無い間は、「印刷」を押せません。

### 印刷区画の境目にかかる物

境目にかかった物の扱いは、ブックのタイプで違います。

| ブックのタイプ | 境目にかかった物 |
|---|---|
| 図面 | 印刷プレビューを開く前に直してもらいます（下の「図面で境目をまたいだとき」） |
| フローチャート | そのまま、紙の境目で切れて刷ります |
| ツリー | 境目にかかる節から後を、次の印刷区画の頭へ送って刷ります |
| ディレクトリ構成図 | 境目にかかる行から後を、次の印刷区画の頭へ送って刷ります |
| マークダウン | 紙の高さで切ります（10 章「マークダウン」） |
| スライド | 境目はありません。紙からはみ出た所は切れて刷ります（10 章「スライド」） |

注: ツリーとディレクトリ構成図で送るのは、印刷するときだけです。書く画面とブックの中身は変わりません。

図面で境目をまたいだとき:

1. 「印刷プレビュー」を押す
2. 印刷プレビューは開かず、右サイドパネルに「印刷区画をまたいだボックスを直してください」と出る。その下に、またいだ物がバッジで並ぶ
3. バッジを押すと、その物の所へ移る。動かして、印刷区画の中に収める
4. またいだ物が無くなると、右サイドパネルに「印刷プレビューを開く」が出る。押すと開く

印刷区画より大きい物:

- 1 つの印刷区画に入らない物は、紙の境目で切れて刷ります。印刷プレビューは開けます
- 右サイドパネルに「印刷区画より大きいので、紙の境目で切れます」と出て、その物がバッジで並びます

注: AI が印刷プレビューで画面に出したときも、同じく確かめます。

## 13. 伝言とマーク

紙の上の物に、AI へ伝えたい事を付けます。文で伝えるのが「伝言」、文を書かずに指して見せるのが「マーク」です。

付けられる物: 箱・形・絵・リスト・データ・線・リストの行・ツリーの節・ディレクトリ構成図の行。プラグインで足した物にも付けられます（2 章「右クリックのメニュー」）。

注: 紙の何も無い所やページには付けられません。
注: ロック中のブックにも付けられます。

### 伝言を書く

1. 物を右クリックし、メニューの「AIに伝言」を押す
2. 画面の右に右サイドパネルが開く。上に「伝言を付ける先」の物の名前が、バッジで並ぶ
3. 付ける先の物に、鳥が飛んでくる
4. 文を書く（文を書く所は 4 行の高さから始まり、書いた分だけ下へ伸びます）
5. 「付ける」を押す（Ctrl+Enter でも付きます。Mac は ⌘+Enter）

- 文が無い間は「付ける」を押せません。空白だけの文も同じです
- 付けると、右サイドパネルが閉じます

注: いくつか選んでいるときに、その 1 つを右クリックして「AIに伝言」を押すと、選んでいる物の全部が付ける先になります。

付けずにやめる:

- Escape を押す
- 右サイドパネルの閉じるボタンを押す

どちらも、書きかけの文は捨てられ、選択も外れます。

注: 紙の何も無い所を押しても、右サイドパネルは閉じません。付ける先と選択が外れるだけで、書きかけの文は残ります。物を押せば、また付ける先になります。

### 付ける先を変える

右サイドパネルを開いている間は、物を押しても選ぶだけです。物は動きません。

- 物を押す: 付ける先がその物に替わります
- Mod+クリック: 付ける先に足します。付ける先の物なら外します
- 紙の何も無い所からドラッグする: 四角にかかった物が付ける先になります
- 別の伝言の吹き出しを押す: その吹き出しの物を押したのと同じです（Mod なら足す・外す）
- 鳥を押す: 「外す？」が出ます。「はい」で、その物を付ける先から外します

Mod は、Windows・Linux では Ctrl、Mac では ⌘ です。

- 付ける先を替えても、書きかけの文は残ります
- 箱の中の物とリストの行のように、ふだんは一緒に選べない物も、一緒に付ける先にできます
- 最後の 1 羽を外すと、付けずに右サイドパネルが閉じます

注: 書いている間に、付ける先の物が消されると（AI が消したなど）、文の欄の上に「付ける先の物が消されました」と出ます。書きかけの文は残ります。付ける先が 1 つも無い間は付けられません。

### バッジとカレント

付ける先のうち 1 つが「カレント」です。カレントのバッジは色が違います。付けた伝言の吹き出しは、カレントの物の右に出ます。

- バッジを押すと、その物がカレントになります
- 長い名前は、バッジには始めの 10 字だけが出ます。ポインタを乗せると全部が出ます
- 付ける先が 2 つ以上なら、紙の上のカレントの物に明るい枠が重なります。カレントを替えると、枠も移ります

右サイドパネルは、付ける先を画面に見せます。

| 変わった事 | 見せ方 |
|---|---|
| 開いたとき・付ける先が増えたり減ったりしたとき | 付ける先が 1 つなら倍率 100%、いくつかなら全部が入る倍率（100% まで）にして、真ん中へ |
| カレントだけが替わったとき | 倍率はそのままで、カレントを真ん中へ |

### 鳥

右サイドパネルで伝言を出している間は、付ける先のそれぞれの上の辺を鳥が歩きます。付ける先が線なら、マークの鳥と同じく、線に沿って歩くか、線の周りを飛びます（「マーク」）。

- 付ける先を足すと、新しい鳥が飛んできます
- 付ける先が替わると、外れた物の鳥が、新しい物へ飛んで移ります
- 外した物の鳥と、閉じたときの鳥は、飛び去ります

注: 動きを減らす OS の設定では、鳥は飛びません。
注: 付ける先の上の辺が画面の外に出ると、鳥は丸い絵に替わります（「付けた物が見えないとき」）。

### 付けた伝言

付けた伝言は、カレントの物の右に吹き出しで出ます。

- 吹き出しには、文の始めの 20 字が出ます
- 吹き出しには、物の方へ曲がる小さな尾が付きます。尾はいつも吹き出しの左に出ます

物の右に吹き出しが入らないとき:

- 吹き出しは動かず、物の右に付いたままです。左に回らず、物にも重なりません
- ステージの右の端に押されて、吹き出しの幅が縮みます

注: 画面を分割しているときは、ステージの境目が右の端です。境目をドラッグしてステージを狭めても、同じに縮みます。
注: 右サイドパネルを開け閉めしたり、境目をドラッグしたりして、ステージの幅が変わると、吹き出しは物の右に付き直します。

物の右の辺がステージの右の端に近すぎて、いちばん細くしても入らないとき:

- 吹き出しは出ません
- 物が画面の外に出たときと同じく、画面の縁にマークポインタが出ます（「付けた物が見えないとき」）
- マークポインタを押すと、物が見えて、吹き出しに戻ります
- ステージを広げても、吹き出しに戻ります

物がステージより広く、物を見せても吹き出しが入らないとき:

- マークポインタのままです
- マークポインタにポインタを乗せると「伝言を開く」と出ます
- 押すと、右サイドパネルにその伝言が出ます（吹き出しを押したときと同じ）

AI が読んだ伝言は、吹き出しを出しません。物の右上の角に、緑の丸のチェックだけが出ます（「AI とのやり取り」）。

注: 文か付ける先を変えて再送すると、AI はまだ読んでいない扱いに戻り、前の吹き出しか、たたんだ絵がまた出ます。

吹き出しを押すと、右サイドパネルにその伝言が出て、付けた先の物が選ばれます。右サイドパネルでは次ができます。

| 操作 | 効く時 |
|---|---|
| 文を直す | 「再送」を押したとき |
| 付ける先を変える（「付ける先を変える」と同じ。鳥で外すのも） | 「再送」を押したとき |
| 隠す・表示 | 押したとき |
| 消す | 押したとき |

注: 「隠す・表示」は、AI がまだ読んでいない伝言にだけ出ます。

- 「再送」は、文か付ける先を変えるまで押せません。再送すると閉じます
- 隠すと、吹き出しの代わりに、物の右上の角に伝言の絵（たたんだ伝言の絵）が出ます。絵を押しても右サイドパネルに出ます
- 「表示」で、吹き出しに戻ります

注: 右上の角に出る物が 1 つの物に 2 つ以上あるときは、1 つにまとまります（「コーナーステータス」）。
注: 右サイドパネルに 1 度に出る伝言は 1 つです。

#### ポインタを乗せて隠す・表示・消す

右サイドパネルを開かずに、紙の上で隠す・表示・消すができます。

| ポインタを乗せる所 | 出る物 | 「はい」を押すと |
|---|---|---|
| 吹き出し | 吹き出しの上に「隠す [はい]」 | 角の伝言の絵になる |
| 角の伝言の絵 | 「表示 [はい]　消す [はい]」 | 表示: 吹き出しに戻る。消す: 伝言が消える |

- 「隠す [はい]」は、右の端を吹き出しの右の端にそろえて出ます。上に入らないときは下に出ます
- 角の伝言の絵が、角のまとまった印の吹き出しの中にあるときは、吹き出しの開いた向きに出ます（「コーナーステータス」）
- 消すの「はい」だけ、色が違います
- ポインタが離れて少し経つか、ほかの所を押すか、Esc で閉じます

次のときは出ません。右サイドパネルのボタンを使います。

- タッチで操作しているとき
- AI が読んだ伝言のチェック
- 右サイドパネルがほかの伝言を出していて、角の伝言の絵が押せない間

注: 伝言の吹き出しと、角に出る印（たたんだ伝言の絵・チェック・びっくりマーク）は、右クリックしても何も出ません。

閉じる:

- Escape か、右サイドパネルの閉じるボタン
- 開いているページを替えたとき・画面を分割したとき

注: 紙の何も無い所を押しても閉じません（「伝言を書く」と同じ）。
注: 開いている間に紙をずらすか倍率を変えなければ、閉じると、開く前の見え方に戻ります。
注: 閉じて右サイドパネルが引っ込んでいく間に、紙をずらすか倍率を変えたときも、開く前の見え方には戻しません。

### 送信トレイ

開いているブックの伝言とマークを、一覧で見ます。

1. 見たいブックを開いているステージで、フッタメニューの「左サイドパネルを開く」を押す
2. 左サイドパネルのタブ「送信トレイ」を押す（最初に開くのは郵便箱のタブです）

- 出るのは、手順 1 のステージで開いているブックの物です。そのステージでブックを替えると、中身も替わります
- 分割しているときは、もう片方のステージの「左サイドパネルを開く」を押すと、そのステージのブックに替わります（2 章「左サイドパネル」）
- コントロールセンターを前に出しても、送信トレイは同じブックの物を出したまま残ります

並び方:

- ページごとに、ページの並びの順で分かれます。見出しはページの名前です
- ページの中は、付けた時刻の新しい順です
- 付けた物のページが分からない物は、最後の「ほか」に並びます
- 1 つも無ければ「伝言もマークもありません」と出ます

1 行に出る物:

| 物 | 中身 |
|---|---|
| 絵 | 伝言かマークの種類の絵 |
| 文 | 伝言は文の始めの 20 字。マークは付けた物の名前 |
| 既読 | AI が読んだ物。行が薄くなります |
| 時刻 | 付けた時刻。今日なら「時:分」、ほかの日は「月/日 時:分」 |

行を押すと、付けた物を見せます。左サイドパネルは開いたまま残るので、続けてほかの行を押せます。

- 伝言: 右サイドパネルにその伝言が出ます（「付けた伝言」）
- マーク: 倍率はそのままで、付けた物が画面の真ん中に来ます
- ほかのページの物なら、先にそのページを開きます

取り消す:

1. 行の「取消」を押す
2. 「取り消しますか？」が出る
3. 「取消」で消えます。「やめる」で消しません

注: 取り消した伝言とマークは「元に戻す」で戻りません。

### 伝言が消えるとき

- 右サイドパネルの「消す」を押したとき
- 送信トレイの「取消」で取り消したとき
- 伝言期限が過ぎたとき（下の「伝言期限」）
- 付けた物が全部消えたとき。いくつかの物に付けた伝言は、残った物に付いたままです

AI が読んだだけでは消えません。読まれた伝言は、既読になって残ります。

注: 伝言は「元に戻す」で戻りません。

#### 伝言期限

AI が読んだ伝言は、そのあと AI に話しかけた時から数えて、伝言期限が過ぎると消えます。

1. AI が伝言を読む
2. 次に AI に話しかけると、数え始める
3. 伝言期限が過ぎると消える

伝言期限は、設定画面の「全体」の「伝言期限」で選びます（15 章）。

読まれた伝言を右サイドパネルで開くと、文の下に、消えるまでの見込みが出ます。

| 様子 | 出る文（例） |
|---|---|
| まだ AI に話しかけていない | 「AI に話しかけてから 60 分で消えます」 |
| 数え始めた | 「AI既読です。あと 23 分で消えます」 |

- 時間は、選んだ伝言期限です。1 時間以上なら「2 時間 10 分」のように出ます
- 伝言期限が「即時」なら「AI に話しかけるとすぐ消えます」と出ます
- 残りが 1 分を切ると「AI既読です。まもなく消えます」と出ます

注: 伝言期限が「消さない」なら、見込みは出ません。

| 選択肢 | 消える時 |
|---|---|
| 即時 | 話しかけたらすぐ |
| 5分・15分・30分・60分・8時間 | 話しかけてから、その時間が過ぎたら |
| 消さない | 消えません |

既定は 60分です。

- 数え始めたあとに話しかけても、数え直しません
- 文か付ける先を変えて再送すると、AI はまだ読んでいない扱いに戻り、数えるのも止まります
- 右サイドパネルで文か付ける先を変えている間は、期限が過ぎても消えません

注: 数え始めるには、AI のフックで `matomezu talked` を呼ぶ必要があります（「AI とのやり取り」）。呼ばないと、読まれた伝言は消えません。Claude Code は、matomezu のプラグインを入れれば呼ばれます（16 章「Claude Code のプラグイン」）。
注: 利用者が打たずに AI が動き出したとき（16 章「画面の操作で AI を動かす（Claude Code）」）は、話しかけた事になりません。数え始めません。
注: 期限が過ぎてから消えるまで、1 分ほどかかることがあります。

### AI とのやり取り

- 伝言を付ける・直す・消すのは人だけです
- AI は伝言を読み、読んだと知らせます。返事は書きません
- 文か付ける先を変えて再送すると、AI はまだ読んでいない扱いに戻ります

AI が読んだと知らせると:

- 画面の上から帯が下りて、「AIが伝言を読みました」と流れます。いくつかまとめて読まれても 1 回です
- 送信トレイで、その伝言が「既読」になります
- 紙の上の吹き出しと、たたんだ伝言の絵が消えます。代わりに、物の右上の角に緑の丸のチェックが出ます。ポインタを乗せると「AI既読: 」に続けて文の始めの 20 字が出ます
- チェックを押すと、右サイドパネルにその伝言が出ます

注: 1 つの物に読まれた伝言が 2 つ以上あると、チェックは角にまとまります（「コーナーステータス」）。

注: マークは、AI が読んでも紙の上では変わりません。既読かどうかは送信トレイで見ます。

右サイドパネルで付けた伝言の文か付ける先を変えると、再送するか閉じるまで、AI はその伝言に手を出せません（編集ロック）。

- AI が読んだと知らせても、断られます
- 伝言を付けた物を、AI は消せません
- 再送するか閉じれば、AI はまた行えます

注: 開いて見ているだけなら、編集ロックは掛かりません。
注: 編集ロックで断られても、画面には何も出ません。AI は後でやり直します。

AI が伝言に気づくのは、AI が matomezu のブックを読んだときです。話しかけるたびに AI へ知らせるには、AI のフック（利用者が話しかけたときに動くもの）で次の 2 つを呼びます。

注: Claude Code は、matomezu のプラグインを入れれば、この 2 つが呼ばれます。下の手順は要りません（16 章「Claude Code のプラグイン」）。

- `matomezu annotations`: AI がまだ読んでいない伝言とマークと、見られる前に消えた AI の変更（11 章）と、反映できなかった変更提案郵便（14 章）を書き出します。無いときは何も出しません
- `matomezu talked`: 話しかけた事を matomezu に知らせます。読まれた伝言の伝言期限が数え始まります

呼ぶ順:

1. `matomezu annotations` を呼び、出た文を取っておく
2. その文を `--context` に付けて `matomezu talked` を呼ぶ（`matomezu talked --context "（出た文）"`）
3. `matomezu talked` には、フックが受け取った入力をそのまま渡す（標準入力）
4. `matomezu talked` の `--host` に、AI のプログラムのプロセス id を付ける

- `matomezu talked` が、AI に添える文をまとめて出します
- フックの入力を渡すと、AI の参加を知らせる事もできます（16 章「AI の参加」）
- `--host` を付けると、/clear でセッションが替わっても同じ参加者のまま続きます（16 章「/clear のあと」）

どちらも、matomezu が起動していないときは何もしません。

注: matomezu が起動していないとき、`matomezu talked` は `--context` の文だけを出します。

`matomezu annotations` が書き出す、まだ読まれていない伝言とマーク:

- ブックごとに、ブックの名前の見出しが出ます
- その下に、伝言とマークが 1 つ 1 行で並びます。行には、どのページの物かが出ます
- 伝言の行には、文の始めの 40 字が出ます
- マークの行には、マークの種類だけが出ます

注: 文が 40 字より長い伝言は、「…」と全体の字数で終わります。AI はページを読んで全文を確かめてから、読んだと知らせます。
注: 伝言やマークを付けた物は、行には出ません。AI はページを読んで確かめます。
注: 全文を出さないのは、話しかけるたびに AI へ送る文を短くするためです。

### マーク

文を書かずに、物を AI に指して見せる印です。

1. 物を右クリックし、メニューの「AIに示す」を押す
2. 物のそばに、マークの種類が並ぶ
3. 付けるマークを押す（Esc で付けずに閉じます）

マークの種類: ツナギドリ・インコ・文鳥・スズメ・フクロウ・びっくりマーク。

- 鳥のマークは、物の上の辺を歩きます。線に付けたときは下の表のとおりです
- びっくりマークは、物の右上の角に付きます（「コーナーステータス」）
- マークを押すと「外す？」が出ます。「はい」で外れます
- 1 つの物に付くマークは 1 つです。別のマークを付けると入れ替わります
- AI も、話が済んだらマークを外します
- 付けたマークは送信トレイにも並びます。AI が読んだマークは「既読」になります。「取消」でも外せます（「送信トレイ」）

線に付けた鳥のマーク:

| 線の形 | 鳥の動き |
|---|---|
| ほぼ横向き（横から 10° まで）で、鳥の幅の 2 倍以上の区間がある線（折れ線なら、その中で一番長い区間） | その区間の上を歩く。体は区間の傾きに合わせて傾く |
| そういう区間が無い線（縦・急な斜めだけ、横の区間が短い） | 線の真ん中の周りを、ぐるぐる飛ぶ |

注: 動きを減らす OS の設定では、鳥は歩かずに正面を向いて止まります。線に付けた鳥は、歩く区間の真ん中（周回する線なら線の真ん中）に、線の向きに合わせて止まります。

鳥の見た目は、どの鳥も決まった色です。色を選ぶ所はありません。

### コーナーステータス

物の右上の角に出る印を「コーナーステータス」と呼びます。次の 3 つです。

- びっくりマーク（「マーク」）
- たたんだ伝言の絵（「付けた伝言」）
- AI が読んだ伝言のチェック（「AI とのやり取り」）

注: 入れているプラグインによって、コーナーステータスは増えます。

1 つの物に 1 つだけなら、角にそのまま出ます。押すと、それぞれの印を押したのと同じです。

2 つ以上なら、角に 1 つにまとまります。

- まとまった印は、並びの先頭の 2 つの絵を重ねた絵です
- 並びは、設定画面の「コーナーステータスの並び」の順です（15 章）。同じ種類の中は、付けた時刻の新しい順です

まとまった印から選ぶ:

1. まとまった印にポインタを乗せる（押す・Enter でも開きます）
2. 角から上へ、小さな吹き出しが開く。吹き出しの右端は角にそろいます
3. 吹き出しに印が横 1 列に並ぶ。選ぶ印を押す

注: 上に入らないときは、吹き出しは下へ開きます。

吹き出しが閉じるとき:

- ポインタが離れて 0.4 秒経ったとき
- Esc を押したとき
- ほかの所を押したとき

ほかに:

- 吹き出しの中のびっくりマークを押すと、「外す？」が吹き出しの開いた側に出ます
- 右サイドパネルがほかの伝言を出している間は、角のたたんだ伝言の絵とチェックは薄くなり、押せません（1 つだけのときも）

### 付けた物が見えないとき

紙をずらして、マークや伝言が付いた物の上の辺が画面の外に出ると、印が画面の縁に寄ります。縁に出る小さな丸を「マークポインタ」と呼びます。

| 印 | 画面の外にある間 |
|---|---|
| 鳥（マークと、伝言の鳥） | 鳥の顔の丸に替わり、画面の縁を歩く |
| びっくりマーク | 画面の縁に寄り、少し薄くなる |
| AI がまだ読んでいない伝言（吹き出しか、たたんだ絵） | 丸の中に伝言の絵が入ったマークポインタに替わり、画面の縁に出る |
| AI が読んだ伝言（緑の丸のチェック） | 緑の丸のチェックのマークポインタに替わり、画面の縁に出る |

注: 伝言の吹き出しは、物がステージの右の端に近すぎて吹き出しが入らないときも、マークポインタに替わります（「付けた伝言」）。
注: 右上の角の印（コーナーステータス）は、1 つの物につき 1 つだけ画面の縁に出ます。並びの先で、縁に出る印の物です。

マークポインタにポインタを乗せると、「（付けた物の名前）を見せる」と出ます。押すと、付けた物を見せます。

- 倍率はそのままで、紙がずれて、付けた物が画面の真ん中に来ます
- 紙の端の近くでは、ずらせる所までずれます
- 見えると、マークや伝言は元の場所と姿に戻ります（伝言は吹き出しか、たたんだ絵か、緑の丸のチェックに戻ります）

注: 画面の外にある間は、押しても「外す？」は出ません。

リストの行に付けたマークは、リストの中のスクロールで行が隠れたときも、リストの行の並びの縁にマークポインタを出します。

- リストごと画面の外にあるときは、画面の縁に出ます
- 押すと、紙がずれ、リストの中もスクロールして、その行を見せます

注: マークポインタどうしが重なることがあります。

### 物の名前

右サイドパネルのバッジと、マークポインタに出る名前は、次の順で決まります。

1. キャプション
2. キャプションが無ければ、本文の最初の行
3. どちらも無ければ、物の種類の名前（「線」など）

- リストの行は、行のキャプションか本文です
- ツリーの節とディレクトリ構成図の行は、節や行に書いた名前です
- 太字や文字の色は外して出ます
- 箱の中の物は、その物の名前です（入れた箱の名前ではありません）

## 14. 郵便

AI から人へ届く知らせです。伝言（人から AI へ）の逆の向きです。

AI が送る郵便は「手紙」です。手紙は次を持ちます。

- 題
- 本文（無いこともあります）
- 送り手: AI が名乗る名前（作業の名前など）
- 行き先: 見てほしい所。ブック、そのページ、ページの上の物まで示せます（無いこともあります）

届いた郵便は、どのブックを開いていても、同じ 1 つの「郵便箱」に入ります。

AI が送る郵便には、手紙のほかに「変更提案」があります。AI が変えられなかった変更を届け、人が押すと反映されます（下の「変更提案郵便」）。

### 届いたとき

1. 画面の上から帯が下りて、「郵便が届きました: （題）」と流れる
2. 画面の右上から、しおりがぶら下がる

- 帯は、フォーカスのある窓か、最後にフォーカスされた窓に出ます
- しおりは、その郵便を見るまで残ります

注: matomezu を開く前に届いていた郵便では、帯は出ません。しおりは出ます。

### しおり

まだ見ていない郵便の数で、出方が替わります。

| まだ見ていない郵便 | しおり | 押すと |
|---|---|---|
| 3 通まで | 1 通に 1 つ。新しい順に左から並び、1 つずつ色が違う | その郵便のダイアログが開く |
| 4 通から | 1 つにまとめ、数が出る | ブックスクリーンが前に出て、左サイドパネルが開く |

しおりは細い帯で、封筒の絵が出ます。

- 1 通に 1 つのしおりを押しても、前に出ている物は替わりません。コントロールセンターが前なら、その上にダイアログが開きます
- まとめたしおりで開く左サイドパネルは、「左サイドパネルを開く」で開くのと同じです（郵便箱と、ブックスクリーンの今のステージの送信トレイ）

ポインタを乗せると、しおりが少し下がり、すぐ下に吹き出しで郵便の題が出ます。

- 待たずにすぐ出ます
- ポインタを離すと消えます
- キーボードの Tab でしおりを選んでも出ます

注: 吹き出しが出るのは、1 通に 1 つのしおりです。4 通からの、まとめたしおりでは出ません。

### 郵便箱

1. ステージのフッタメニューの「左サイドパネルを開く」を押す（4 通からなら、まとめたしおりを押しても開きます）
2. 一番左のタブ「郵便箱」が開く

- 届いた郵便が、新しい順に並びます
- 1 つも無ければ「郵便はありません」と出ます

1 行に出る物:

| 物 | 中身 |
|---|---|
| 点 | まだ見ていない郵便に付きます |
| 送り手 | AI が名乗った名前 |
| 題 | 始めの 24 字 |
| 時刻 | 届いた時刻。今日なら「時:分」、ほかの日は「月/日 時:分」 |
| 印 | 変更提案郵便だけ。題のあとに「反映済み」か「反映できませんでした」 |

行を押すと、その郵便のダイアログが開きます。

- 前に出ている物は替わりません。コントロールセンターが前なら、その上にダイアログが開きます
- ブックスクリーンが前に出るのは、ダイアログの開くボタンを押したときです（下の「行き先を開く」）

取り消す（郵便箱から消す）:

1. 行の「取消」を押す
2. 「取り消しますか？」が出る
3. 「取消」で消えます。「やめる」で消しません

注: 消した郵便は「元に戻す」で戻りません。
注: 入れているプラグインが止めているときは、「取消」が薄くなって押せません。断られたときは、トーストに「取り消せませんでした」と出ます（17 章）。
注: 郵便箱には 200 通まで残ります。超えると、見た郵便の古い物から消えます。見た郵便が無ければ、古い物から消えます。

### 郵便のダイアログ

しおりか郵便箱の行を押すと開きます。

- 見出し: 題
- 送り手と、届いた日時
- 本文

ダイアログを開くと、その郵便は「見た」ことになります。しおりと、未読の数から外れます。

閉じる:

- Escape を押す
- ダイアログの外を押す
- 下の行の「閉じる」を押す

どれで閉じても、郵便箱（左サイドパネル）は開いたまま残ります。続けてほかの郵便を開けます。

ダイアログと郵便箱を一緒に閉じる:

- 下の行の「郵便箱も閉じる」を押す

注: 「郵便箱も閉じる」は、左サイドパネルで郵便箱のタブが開いているときだけ、下の行の左端に出ます。しおりから開いたときなど、郵便箱が開いていなければ出ません。

### 行き先を開く

ダイアログの下の行に、開くボタンが並びます。

注: 変更提案郵便では、開くボタンの代わりに「場所を示す」と「反映」が並びます（下の「変更提案郵便」）。
並ぶボタンは、画面を分割しているかで替わります。

| 画面 | 下の行のボタン |
|---|---|
| 分割していない | 閉じる・開く・分割で開く |
| 左右に分割している | 閉じる・左に開く・右に開く |

注: 郵便箱のタブが開いていれば、「閉じる」の左に「郵便箱も閉じる」が出ます。

| ボタン | 開く所 |
|---|---|
| 開く | 今のステージ |
| 分割で開く | 画面を分割して、右に足したステージ |
| 左に開く・右に開く | 左か右のステージ |

1. 開くボタンを押す
2. ダイアログが閉じる
3. 行き先のブックとページが開く

左サイドパネルを開いていれば、閉じずにそのまま残ります。開いているタブも替わりません。

注: 送信トレイは、行き先を別のステージに開いても、左サイドパネルを開いたステージのブックを出したままです。行き先のブックを出すには、そのステージの「左サイドパネルを開く」を押します（2 章「左サイドパネル」）。

- Enter を押すと、ダイアログを出したステージで開きます（分割していなければ「開く」、分割していれば、そのステージの側の「左に開く」か「右に開く」）
- ダイアログは、ブックスクリーンの今のステージで開きます
- コントロールセンターが前に出ているときは、開くボタンでブックスクリーンが前に出て、そこで開きます
- 行き先がブックだけのとき: そのブックを開いていれば、ページは替わりません。開いていなければ、そのブックの最初のページが開きます
- 「分割で開く」で開くと、右のステージが前に出ます
- 「分割で開く」のあと、ブラウザの戻るを 1 回押すと、分割する前に戻ります

行き先の無い郵便では、下の行に「閉じる」だけが出ます。行き先のブック・ページ・物が無くなっているときも同じで、「行き先がありません」と出ます。

注: ゴミ箱に入れたブックも、無くなった扱いです。

### 示された物を知らせる鳥

行き先に物が示されている郵便を開くと、次の順に動きます。

1. 倍率はそのままで、その物が画面の真ん中に来る
2. 鳥が 1 羽、その物の上に飛んでくる（鳥は毎回違うことがあります）
3. 鳥が降りると、示された物それぞれの枠が点滅する
4. 鳥がその鳥の仕草を 1 回して、飛び去る。そのとき枠も消える

- 途中で別のブックやページを開くと、鳥も枠も消えます
- 開くボタンを使わず、自分でその場所を出したときは、鳥も枠も出ません

- 物が画面の外へずれても、鳥は画面の中の縁に寄って見えたままです（マークや伝言の鳥のような丸い絵には替わりません）

注: 動きを減らす OS の設定では、鳥は飛ばずに降りた所で正面を向いて止まり、仕草の分だけ出てから消えます。枠は点滅せずに出るだけです。

### 未読の数

まだ見ていない郵便の数が、次の 2 か所に丸い印で出ます。

- フッタメニューの「左サイドパネルを開く」の角（ポインタを乗せると「未読 （数）」）
- 左サイドパネルの「郵便箱」のタブの名前の横

0 通なら出ません。100 通からは「99+」と出ます。

### AI が知る事

AI は、送った郵便について次の 2 つを知れます。

| AI が知る事 | そうなる時 |
|---|---|
| 郵便を見た | 郵便のダイアログを開いたとき |
| 行き先を見た | ダイアログの開くボタンで開いたとき。または、自分でその行き先を画面に出したとき（そのページを開き、示された物が画面に入ったとき） |

- 2 つは別々です。ダイアログを開かずに、行き先だけ見たことにもなります
- 郵便は画面からは送れません。AI が送ります
- 郵便を消せるのは人だけです（郵便箱の「取消」）

### AI が郵便箱を読むとき

AI は、郵便箱を次の順で読みます。

1. 新しい順に 20 通の、題だけの一覧を読む
2. 要る郵便だけ、本文まで読む

一覧で AI が知る事:

- 送り手・届いた時点・行き先
- 郵便を見たか・行き先を見たか（「AI が知る事」）
- 郵便の題
- 絞りに合う郵便が全部で何通か、一覧より古い郵便が何通残っているか

一覧の取り方は、AI に頼んで変えられます。

| 頼む事 | 例 |
|---|---|
| 並べる数を変える（100 通まで） | 「郵便を 50 通見て」 |
| もっと古い郵便へさかのぼる | 「その前の郵便も見て」 |
| まだ見ていない郵便だけにする | 「まだ開いていない郵便は？」 |
| もう見た郵便だけにする | 「もう開いた郵便は？」 |
| 行き先をまだ見ていない郵便だけにする | 「行き先を見ていない郵便は？」 |
| 行き先を見た郵便だけにする | 「行き先を見てくれた郵便は？」 |
| 行き先が、あるブックの郵便だけにする | 「このブックを示す郵便は？」 |

- 絞り方は、組み合わせられます（例: 「このブックを示す郵便で、まだ開いていない物は？」）
- 本文まで読むのは、一度に 20 通までです
- 郵便がたくさんあっても、AI は要る所だけを読みます

注: プラグインで足した種類の郵便は、一覧に題が出ないこともあります。そのときは、AI は種類でだけ見分けます（17 章）。

注: AI が郵便箱を読んでも、画面には何も出ません。既読にもなりません。

### 変更提案郵便

人が直している物は、AI が変えられません（16 章「人が直している間」）。そのとき AI は、変えたかった事を変更提案郵便で送れます。

例: 箱の編集のダイアログを開いている間に、AI がその箱の色を変えようとして断られた。AI が「色を赤にする」変更提案郵便を送る。

届き方は、ほかの郵便と同じです（帯・しおり・郵便箱）。

1. 直していたダイアログを閉じる
2. しおりか郵便箱の行を押して、郵便のダイアログを開く
3. 本文で、AI が何をなぜ変えるかを読む
4. 「場所を示す」を押して、変わる所を見る
5. 「反映」を押す

郵便のダイアログの下の行:

| ボタン | すること |
|---|---|
| 閉じる | 反映せずに閉じる。郵便は残り、後で反映できます |
| 場所を示す | 郵便を閉じずに、変わる所を見せる |
| 反映 | 変更をブックに入れる |

「場所を示す」を押すと:

- 郵便のダイアログが、窓の右の端に寄ります。後ろは暗くなりません
- ダイアログを出したステージで、行き先のブックとページが開きます
- 変わる物が画面の真ん中に来て、鳥が来ます（上の「示された物を知らせる鳥」）

「反映」を押すと:

- 変更がブックに入り、郵便のダイアログが閉じます
- 郵便箱の行に「反映済み」が出ます
- 元に戻す 1 回で、反映した変更が全部戻ります（11 章）

反映できないとき:

| そうなる時 | 出る物 | 郵便 |
|---|---|---|
| ほかの窓やタブで、その物を直している | トースト「直している最中です」「直し終えてから反映してください」 | 残ります。直し終えてから、もう一度「反映」を押せます |
| 送られたあとに、その物が変わった・無くなった | トースト「反映できませんでした」「送られたあとに変わっています」 | もう反映できません |
| 変更の一部が断られた | トースト「反映できませんでした」「変更の一部が断られました」 | もう反映できません |

- 反映できなかったときは、ブックは何も変わりません。変更は全部入るか、1 つも入らないかです
- もう反映できない郵便は、郵便箱の行に「反映できませんでした」が出ます
- 反映した・できなかった郵便のダイアログでは、「場所を示す」と「反映」が消えて、「反映済み」か「反映できませんでした」と、その日時が出ます。「閉じる」は残ります
- 反映できなかった事は、次に AI に話しかけたときに AI に伝わります。AI は今のブックを読み直して考え直します

注: ロック中のブックなど、反映を行えないときは、「反映」が薄くなって押せません。
注: AI に伝わるのは、AI のフックで `matomezu annotations` を呼んでいるときです（13 章「AI とのやり取り」）。Claude Code は、matomezu のプラグインを入れていれば呼ばれます（16 章「Claude Code のプラグイン」）。

## 15. 設定

設定画面で変えます。

### 設定画面

1. フッタメニューの基本のボタンの「設定を開く」（歯車）を押す。どのステージからでも開けます
2. 設定画面がダイアログで開く
3. 左の一覧の項目を押すと、右の欄がその項目に切り替わる
4. 見出しの行の「閉じる」で閉じる

左の一覧の項目:

- 全体（下の「全体の項目」）
- マークダウン（下の「マークダウンの項目」）
- ショートカットキー（下の「ショートカットキーを変える」）

注: 入れているプラグインによって、項目は増えます。

### ショートカットキーを変える

設定画面の左の「ショートカットキー」を押すと、右にキーの一覧が出ます。

一覧の作り:

- 見出しは、キーが効く範囲です（下の「範囲」）
- 見出しの下の行は、キーで動く操作です。行の右に、割り当てたキーの札が並びます
- 一覧の上の入力Form「ショートカットキーを探す」に書くと、行が絞り込まれます。行の名前・範囲の名前・キーの名前のどれかに当てはまる行だけが出ます

範囲:

- 画面全体
- ステージ
- ダイアログが開いている間
- メニューが開いている間
- 右サイドパネル
- 左サイドパネル
- リスト
- ツリー
- ディレクトリ構成図
- ソース（マークダウンのブック）
- スライド（スライドのブックの紙の上。10 章「スライド」）
- 検索（検索ダイアログの入力Formの中。10 章「検索と置換」）

注: 入れているプラグインによって、範囲や行は増えます。

キーを外す:

1. 札の × を押す

キーを足す:

1. 行の + を押す
2. 「キーを押してください」と出たら、足したいキーを押す
3. 押したキーの札が増える

- 足すのをやめるときは、「キャンセル」を押す

注: 「キーを押してください」の間は、Escape も足すキーになります。ダイアログは閉じません。

同じキーを使う行があるとき:

- 同じ範囲のほかの行が使っているキーを足すと、「（キー）は「（行）」で使っています。付けるとそちらでは効かなくなります」と出ます
- 「付ける」で付けます。「キャンセル」でやめます
- ほかの行が先に使っていて効いていないキーは、行の下に「（キー）は効いていません（「（行）」が先に使っています）」と出ます

注: 自分で付けたキーは、プラグインが決めたキーより先に効きます。

既定に戻す:

- 変えた行には「既定に戻す」が出ます。押すと、その行だけ戻ります
- 一覧の上の「全部を既定に戻す」を押すと、確かめてから全部を戻します

### 全体の項目

設定画面の左の「全体」を押すと、右に次の項目が並びます。

- 言語
- スキン: 自動・ダーク・ライト・matomezuライト・matomezuダーク。matomezuライトとmatomezuダークは、マスコットの鳥の色の画面です。「自動」は、OS の明暗に合わせてダークかライトを選びます（matomezuライト・matomezuダークは選びません）
- 文字の色: 本文の装飾の 4 色を何色で描くか。どのブックでも、ブックの設定より強く効きます。「なし」で元の色に戻ります
- ツールの切り替えを出す長押しの時間（ミリ秒）: 紙の上で右ボタンを押し続けてから、ツールのアイコンが出るまでの時間。150 から 500 まで、50 ずつ選べます。既定は 250 です。押している間に満ちていく輪も、この時間に合わせて満ちます
- 伝言期限: AI が読んだ伝言を、話しかけてからどれだけで消すか。即時・5分・15分・30分・60分・8時間・消さない から選びます。既定は 60分です（13 章「伝言期限」）
- コーナーステータスの並び: 物の右上の角に出る印の種類の並び（13 章「コーナーステータス」）。行の ↑ で前へ、↓ で後ろへ 1 つ動きます。既定は、びっくりマーク・たたんだ伝言・既読の伝言の順です

注: 入れているプラグインの項目は、プラグインごとの見出しの下に並びます。プラグインが自分の項目を左の一覧に足したときは、そちらに並びます。

### マークダウンの項目

設定画面の左の「マークダウン」を押すと、右に次の項目が並びます。どれも、マークダウンのブックに効きます（10 章「マークダウン」）。

- Tabキー: Tab キーを押したときに書く字。Tab か、半角スペースを選びます。半角スペースなら、数（2 か 4）も選びます。既定は Tab です
- 行番号を出す: 左の列に行番号を出します。既定は入りです
- カーソルのある行に下線を引く: 既定は切りです
- 空白と Tab を見せる: 半角スペース・全角スペース・Tab に印を出します。既定は切りです
- 段落の中の改行: 段落の中で 1 回だけ改行した所を、プレビューのペインと印刷で、改行にするか空白にするか。「改行にする」か「空白にする（GFM方式）」を選びます。既定は改行にするです

注: 上の 4 つはソースのペインに効きます。「段落の中の改行」は、プレビューのペインと印刷に効きます。

## 16. AI と使う

AI に頼めること:

- ブックやページを作る・変える（紙のサイズ・向き・可変ページかと、その増やす向きも）。ブックや箱・リストのテーマは、そのブックで選べるテーマだけです。ほかは断られます（3 章「ブックの設定」）
- ページの並びを変える（ページのタブの並べ替え）
- ページを、並びの好きな所に足す（言わなければ最後。名前を言わなければ「（無題）」）
- スライドのブックのページを複製する（すぐ後ろにでき、伝言とマークとロックは写らない。ほかのタイプのブックでは断られます）
- アイテムを置く・動かす・変える・消す、線を引く
- 図面とフローチャートのアイテムを、写して貼る（中のアイテムと、間の線ごと。ほかのページやブックへも。データは写せません。7 章「コピー・切り取り・貼り付け・複製」）
- 図面の箱の中にアイテムを置く・入れる・出す
- 空いている所にアイテムを置く（置く所を言わなければ、AI はほかのアイテムを動かさない空きを探して置きます）
- 物の位置と大きさを、紙の上で見たとおりに読んで、並びをそろえる
- リストの行を足す・チェックする
- データの表を丸ごと入れ替える、見た目・キャプションと本文・使う列を変える（表と一緒に一度で変えることもできます）
- ツリーの節や、ディレクトリ構成図のフォルダとファイルを足す
- ディレクトリ構成図を、パスの一覧から組み立てる（パスから足す。画面からはできません）
- フローチャートを自動で整列する
- スライドに文字枠・自由な線・直線・楕円を置く・動かす・大きさを変える・消す。色・線の太さ・文字の大きさ・角度・重なりの前後（いちばん前・いちばん後ろ・1 つ前・1 つ後ろ）も変えられます（10 章「スライド」）
- マークダウンのページの文書を書く。丸ごと書き換えるか、1 か所だけ置き換える
- 印刷プレビューの設定（「紙を並べる向き」「区画を数える順」「ページ番号を入れる」「ブック名を入れる」「ページ名を入れる」）を変える（12 章）
- ブックを印刷プレビューで画面に出す。今の画面が印刷プレビューかを知る
- 伝言を読んで、読んだと知らせる・マークを外す（13 章）
- 人に郵便（手紙）を送る。送った郵便を見たか・行き先を見たかを知る（14 章）
- 郵便箱を読む。新しい順の題の一覧から読み、要る郵便だけ本文まで読む。まだ見ていない郵便だけ・行き先を見ていない郵便だけ・行き先が、あるブックの郵便だけにも絞れる（14 章「AI が郵便箱を読むとき」）
- 人が直していて変えられなかった物の変更を、変更提案郵便で送る（14 章「変更提案郵便」）
- ブックを画面に出す
- ツールの切り替えを出す長押しの時間と、伝言期限と、コーナーステータスの並びを変える（15 章）
- ワークルームへの参加を頼む。続けたいワークルーム名（空室の名前でもよい）や、始めたい名前を添えられる。引き継ぐか新しく始めるかは人が選ぶ（下の「AI の参加」）
- タスクボードのプロジェクトとチケットを読む。プロジェクトを足す。チケットを足す・直す・ロックする。チケット履歴を書く・読む。自分の今のチケットを知らせる（18 章）
- スクラップトレイを読む。図面とフローチャートにスクラップを置く。置いたスクラップの大きさと枠線を変える（20 章「AI とスクラップ」）

人だけができること:

- ロックを外す
- 伝言を付ける・直す・消す（送信トレイの取消も）、マークを付ける
- 郵便を見る・郵便箱から消す
- 変更提案郵便を反映する
- ゴミ箱から戻す、完全に消す
- 印刷する
- AI の参加を、受け入れる・断る。受け入れるときに、引き継げるワークルームに入れるか、新しく始めるかを選ぶ（Claude Code に matomezu のプラグインを入れていれば、受け入れた・断った時に AI が動き出します。下の「画面の操作で AI を動かす（Claude Code）」）
- ワークルームから退室させる・ワークルームを消す・管理者を決める（下の「ワークルームの枠」「退室」）
- ワークルームを作る・変える（作るのは参加を受け入れるときだけです。名前・鳥・配色を後から変える画面は、まだありません）
- タスクボードのプロジェクトを直す・閉じる・開け直す。チケットを消す。チケットのロックを外す（18 章。画面はまだありません）
- スクラップを切り抜いてスクラップトレイに入れる・トレイから消す（20 章）

AI は、ロック中のブックや、画面に出ているブックをゴミ箱に入れられません。そのときは AI がチャットで頼んできます。

AI の変更は、画面に見えたら、元に戻すで戻せます。見る前に元に戻すで消した AI の変更は、次に話しかけたときに AI に伝わります（11 章）。

AI が置く・動かすときは、画面の操作と違い、既定ではほかの物を押しのけません。

- ほかの物が動くなら、AI は置かずに、邪魔になる物と空いている所を知ります
- 押しのけてよければ、そう頼みます（「ほかの物をどけて置いて」など）。画面で置いたときと同じに押しのけます

AI が動かす・箱に入れる・出すときは、画面のドラッグと違い、収まる一番近い所へ寄せません。言われた所に収まらなければ、断られます（7 章「動かす」）。

### Claude Code のプラグイン

Claude Code には、matomezu のプラグインを入れます。入れるだけで、次が揃います。

| 揃う物 | できる事 |
|---|---|
| MCP | AI が matomezu を使える（1 章「AI とつなぐ」） |
| 話しかけたときの知らせ | 話しかけるたびに、まだ読まれていない伝言とマークが AI に届く。読まれた伝言の伝言期限が数え始まる（13 章「AI とのやり取り」）。参加しましたの知らせが出る（下の「参加しましたの知らせ」） |
| モデルの知らせ | セッションが始まったときと、モデルを切り替えたときに、ワークルームの枠のモデルが替わる（下の「モデルとブランチ」） |
| 画面の操作を待つ | 画面で参加を受け入れる・断ると、AI が動き出す（下の「画面の操作で AI を動かす（Claude Code）」） |

- フックを自分で書く要はありません
- /clear のあとも、同じ参加者のまま続きます（下の「/clear のあと」）
- プラグインを入れないと、参加を受け入れても AI はずっと「準備中」のままです（下の「参加しましたの知らせ」）

入れ方（利用者ごとに 1 度）:

1. `claude plugin marketplace add （matomezu のリポジトリ）/clients/claude-code` を打つ
2. `claude plugin install matomezu@matomezu` を打つ

注: 【未確定】この入れ方は開発中の物です。npm で入れた matomezu のときの入れ方は、まだ決まっていません。
注: 前に Claude Code へ手で登録した matomezu の MCP は外します。
注: プラグインの MCP の道具は、Claude Code の上で `mcp__plugin_matomezu_matomezu__` で始まる名前になります。手で登録したときの `mcp__matomezu__` とは違います。

matomezu が見つからないとき（`matomezu` のコマンドが使えないとき）:

- 話しかけたときの知らせ・モデルの知らせ・画面の操作を待つ事は、何もしません。エラーも出ません
- MCP はつながりません

注: matomezu が起動していないだけなら、話しかけたときの知らせとモデルの知らせは何もしません。画面の操作を待つ事は、起動したらつながります。

### AI がブックを読むとき

AI は、ブックを次の順で読みます。

1. ブックのページの一覧（ページの名前と字数）を読む
2. 要るページの中身を読む
3. ページが大きすぎて一度に読めないときは、そう知らされ、物ごとに分けて読む

- 大きなページも、途中で切れたまま読み落とすことはありません
- ページが多いブックや、大きなページのあるブックでも、AI は要る所だけを読みます

注: 一度に読めなかったときも、画面には何も出ません。

注: AI ができる事の一覧も、初めは題名だけを読み、使う物の詳しい所だけを後から読みます。プラグインを足したり外したりすると、この一覧が変わります（17 章）。

### 人が直している間

人が直している物は、AI が変えようとしても断られます（編集ロック）。直し終えれば、AI はまた変えられます。

直しているとするのは、次の間です。

| 直し方 | AI が変えられない物 |
|---|---|
| 物を直すダイアログを開いている | その物と、その中の物（ページの設定なら、そのページとページの上の物の全部） |
| その場で書いている・色や種類を選んでいる | 選んでいる物の全部 |
| マークダウンのソースのペインで書いている（ペインに書く所がある） | そのページ |
| チケットスクリーンで名前を書いている・本文の原文で書いている | そのチケット（18 章「チケットスクリーン」） |

物を直すダイアログ:

- 形・箱・リスト・データ・絵・線の編集
- リストの行の編集
- ツリーの節の大きさ
- ディレクトリ構成図のノードの設定
- ページの設定

- ほかの物は、直している間も AI が変えられます
- ほかの窓やタブで直していても同じです
- 断られた AI は、後でやり直すか、変更提案郵便を送ります（14 章「変更提案郵便」）

注: マークダウンのソースのペインは、開いているだけなら AI が書けます。ペインの外を押すと、AI がまた書けます。
注: 断られても、画面には何も出ません。
注: 伝言を直している間の編集ロックは、13 章「AI とのやり取り」にあります。

### AI の参加

AI は、利用者の「ワークルーム」に参加者として入れます。AI が参加を頼み、人が受け入れます。

ワークルームは次を持ちます。

- ワークルーム名（20 字まで。ほかのワークルームと同じ名前にはできません）
- 鳥
- 配色

1 つのワークルームに入れる参加者は 1 人です。参加者のいないワークルームを「空室」と呼びます。

ワークルームと参加者は、コントロールセンターで見ます（下の「ワークルームの一覧」「ワークルームの枠」）。

1. ステージの下の行のブックの名前にポインタを乗せる
2. 上がったフッタメニューの「コントロールセンター」を押す

参加者の様子は、次の 3 つです。

| 様子 | 意味 |
|---|---|
| 準備中 | 受け入れたが、まだ AI のセッションに参加が伝わっていない（下の「参加しましたの知らせ」） |
| 生きている | AI が最後に matomezu を使ってから、設定の「参加の有効時間」の内にいる |
| 静か | 参加の有効時間を過ぎた |

- 画面に言葉で出るのは「準備中」だけです
- 生きているか静かかは、ワークルームの枠の「最終アクセス」で見ます。参加の有効時間の内なら生きている、過ぎたか「なし」なら静かです
- 生きているか静かかで、引き継げるワークルームが決まります（下の「ワークルームを引き継ぐ」）

「参加の有効時間」は 15分・30分・60分・2時間・8時間 から選びます。既定は 60分です。

準備中の間:

- AI は、ブックと、伝言・マークを使えます
- それ以外（コントロールセンターの物など）は、AI が使おうとしても断られます
- 使っても「生きている」になりません。参加者として数えません

注: matomezu を起動し直しても、AI が最後に matomezu を使った時刻は残ります。参加の有効時間の内なら「生きている」のままです。
注: Codex は、受け入れた時点で準備中になりません。一覧の行は初めから（空き）で、最終アクセスは「なし」です。matomezu を使うと「たった今」になります。
注: Codex のほかの AI は、話しかけたときのフックで参加を知らせないと、準備中が済みません（下の「参加しましたの知らせ」）。Claude Code は、matomezu のプラグインを入れれば知らせます（上の「Claude Code のプラグイン」）。

### ワークルームの一覧

コントロールセンターの左の列の「ワークルーム/参加者」に、ワークルームが 1 つ 1 行で並びます。空室も並びます。

行に出る物:

- ワークルームの鳥（ワークルームの配色で塗られます）
- ワークルーム名
- 名前の下の 1 行: 様子

| 行の見え方 | 意味 |
|---|---|
| 点線の丸と（空室） | 空室 |
| 薄い鳥と（準備中） | 参加者が準備中 |
| チケットの番号と名前（例: T-003 ログイン画面の文言を直す） | 参加者がいて、そのチケットに取り組んでいる（18 章「今のチケット」） |
| （空き） | 参加者がいて、取り組んでいるチケットが無い |
| 高い行で、鳥の頭に金の王冠 | 管理者のワークルーム（下の「ワークルームの枠」）。いつも先頭に出ます |

- ほかの行は、ワークルームを作った順に並びます
- 1 つも無ければ「ワークルームはありません」と出ます
- 参加を頼んでいて、まだ受け入れていない AI は出ません

行を押すと、そのワークルームが選ばれ、プロジェクトの画面の下のワークルームの枠に出ます（下の「ワークルームの枠」）。

注: 選んだワークルームは、読み直すと選ばれていない状態に戻ります。
注: 管理者の行も、ほかの行と同じく、今のチケットか（空き）が出ます。

### ワークルームの枠

コントロールセンターのプロジェクトの画面の下に出ます。一覧で選んだワークルームを見ます。

- 選んでいなければ「選択したワークルームの情報、各種機能（未定）」と出ます
- 空室を選ぶと「（ワークルーム名）（空室）」とだけ出ます

参加者のいるワークルームでは、3 列に分かれます。

1. 情報
2. 現在のタスク
3. 履歴

現在のタスクの列に出る物（ワークルームの今のチケット。18 章「今のチケット」）:

- 「プロジェクト:」と、チケットのプロジェクトの名前
- チケットの番号と名前
- 的の印のボタン「ボードで見る」（下の「ボードで見る」）
- 「最新:」と、そのチケットのチケット履歴の、いちばん新しい行の本文（行が無ければ出ません）

履歴の列には、今のチケットのチケット履歴が、新しい順に並びます。1 行に、書いてからの時間（「5 分前」など）と本文が出ます。

- 今のチケットが無ければ、どちらの列も「なし」と出ます
- 履歴の行が 1 つも無ければ、履歴の列は「なし」と出ます

注: 履歴の列に、行の題（状況・プランなど）は出ません。

情報の列に出る物:

- 鳥・ワークルーム名・王冠
- 最終アクセス: AI が最後に matomezu を使ってからの時間（「たった今」「5 分前」など）
- ブランチ: AI の作業フォルダの git のブランチ（下の「モデルとブランチ」）
- model: AI が今使っているモデル（下の「モデルとブランチ」）
- os: AI の環境
- 右下に、退室のボタン（下の「退室」）

注: 最終アクセスは、まだ一度も使っていなければ「なし」、準備中なら「準備中」と出ます。
注: ブランチは、分からないときは行ごと出ません。

管理者を決める:

1. 管理者にしたいワークルームを、一覧で選ぶ
2. ワークルームの枠の、名前の横の灰色の王冠を押す
3. 王冠が金になり、そのワークルームが一覧の先頭に動く

- 管理者のワークルームは 1 つだけです。ほかを管理者にすると、前の管理者は外れます
- 王冠にポインタを乗せると、管理者なら「管理者」、ほかは「管理者にする」と出ます

注: 管理者を外すだけの操作はありません。
注: 空室は、管理者にできません。

### ボードで見る

ワークルームの今のチケットが、タスクボードのどこにあるかを、ワークルームの鳥が教えます。

1. ワークルームの一覧で、ワークルームを選ぶ
2. ワークルームの枠の、現在のタスクの列の「ボードで見る」を押す
3. そのチケットのプロジェクトのボードが出ていなければ、ボードが出る
4. チケットのカードが見える所まで、ボードがスクロールする
5. ワークルームの鳥が、カードの裏から顔を出して、カードの上の辺に乗る
6. 鳥はすぐ飛び去る

- 鳥が来ている間は、カードに色が付きます。ポインタを乗せたときと同じ色です
- 3 で出したボードは、そのまま出ています。プロジェクトの一覧のチェックも入ります（18 章「プロジェクトの一覧」）

鳥がすぐ消えるとき:

- カードの位置が変わった
- 別の画面やダイアログが、カードの前に来た

注: ボードが出ていなくて、出しているボードを変えられないようになっているときは、「ボードで見る」は押せません。
注: 動きを減らす設定（OS の視差効果を減らす設定など）では、鳥は動かずに、カードの上に出ます。
注: カードが見つからないときは、鳥は来ません。何も出ません。

### 退室

参加者を、ワークルームから出します。

1. 一覧でワークルームを選ぶ
2. ワークルームの枠の右下の、退室のボタン（ポインタを乗せると「退室する」）を押す
3. ダイアログ「退室」が開き、「（鳥）（ワークルーム名）から退室します。」と出る
4. ボタンを 1 つ押す

| ボタン | 起きる事 |
|---|---|
| キャンセル | 何も変えずに閉じる |
| 部屋を出る | 参加者が外れ、ワークルームは空室になって一覧に残る |
| 部屋を削除する（赤） | 参加者が外れ、ワークルームも一覧から消える |

- 空室になったワークルームは、次に参加する AI に引き継げます（下の「ワークルームを引き継ぐ」）
- 変えられなかったときは、変えられなかった訳が出ます

注: 空室のワークルームには、退室のボタンが出ません。空室だけを消すボタンはありません。参加を受け入れるときに、同じ名前で「前のを破棄して新しく始める」を選ぶと消えます（下の「ワークルームを引き継ぐ」）。

コントロールセンターからブックスクリーンへの戻り方は、2 章「コントロールセンターとブックスクリーン」にあります。

### 参加を受け入れる

1. AI が参加を頼むと、郵便「AI エージェントから参加要求が届きました」が届く
2. 郵便のダイアログの「受け入れる」を押す
3. 「ワークルームに入れます」のダイアログが開く
4. ワークルーム名・鳥・配色を決めて「受け入れる」を押す
5. そのワークルームが新しくでき、AI がそこに入る

- 断るときは、郵便のダイアログの「断る」を押します
- 「キャンセル」で閉じると、参加要求は返事をしないまま残ります。郵便からもう一度開けます
- ワークルーム名の初めは、AI が頼んだ名前です。無ければ、AI のセッションの名前です
- AI がワークルーム名を頼んだときは、郵便の本文の頭に「ワークルーム名: （名前）」が出ます

ワークルーム名が、今あるワークルームと同じとき:

- 生きている参加者のいるワークルームと同じ: 「この名前は使われています」と出て、受け入れられません
- 引き継げるワークルーム（下の「ワークルームを引き継ぐ」）と同じ: 「この名前の、静かな参加者がいます」と出ます。受け入れると、確かめの段に進みます

注: 引き継げるワークルームがあるときは、ダイアログの上に「新しく始める」と「引き継ぐ」が出ます。ここで書いたのは「新しく始める」のときです。引き継ぐときは、下の「ワークルームを引き継ぐ」を見てください。
注: 空室と同じ名前のときも、「この名前の、静かな参加者がいます」と出ます。

### 参加しましたの知らせ

受け入れたあと、AI のセッションで利用者が話しかけると、そのセッションに次が出ます。Claude Code に matomezu のプラグインを入れていれば、話しかけなくても、受け入れた時に出ます（下の「画面の操作で AI を動かす（Claude Code）」）。

- 「matomezu に参加しました。ワークルーム名: （ワークルーム名）」
- セッションの名前が、ワークルーム名に替わる
- コントロールセンターの一覧の行から（準備中）が消え、鳥が薄くなくなる。ワークルームの枠の最終アクセスが「たった今」になる

- 知らせは 1 度だけです
- 元のセッションの名前は、matomezu の参加者に残ります

注: これは Claude Code で、matomezu のプラグインを入れているときです（上の「Claude Code のプラグイン」）。ほかの AI は、話しかけたときのフックで `matomezu talked` を呼んでいるときです（13 章「AI とのやり取り」）。
注: プラグインを入れていない Claude Code は、受け入れてもずっと「準備中」のままです。フックの無い AI も同じです。
注: Codex は、フックが無くても準備中になりません（上の「AI の参加」）。
注: 1 つのセッションで 2 人以上が同時に参加したときは、セッションの名前は替わりません。

### 画面の操作で AI を動かす（Claude Code）

Claude Code に matomezu のプラグインを入れると、画面での操作で、AI が自分から動き出します。コンソールに何も打たなくて構いません。

AI が動き出す操作:

| 画面の操作 | AI のセッションで起きる事 |
|---|---|
| 参加要求を受け入れる | 参加が伝わり、「参加しましたの知らせ」が出る（上の「参加しましたの知らせ」） |
| 参加要求を断る | AI が、断られた事をチャットで伝える。利用者が頼むまで、参加を頼み直さない |

- ほかの操作（伝言を付けるなど）では動き出しません。次に話しかけたときに伝わります

注: 動き出すのは、参加を頼んだ Claude Code のセッションだけです。
注: /clear のあとも動き出します。
注: 利用者が打たずに動き出したときは、話しかけた事になりません。読まれた伝言の伝言期限は数え始めません（13 章「伝言期限」）。

- プラグインは、Claude Code の裏で `matomezu watch` を動かします。画面の操作を待ち、届いたら AI を動かします
- matomezu が起動していない間は待ち、起動したらつながります
- Claude Code を閉じると、`matomezu watch` も止まります

入れ方は、上の「Claude Code のプラグイン」にあります。

### モデルとブランチ

ワークルームの枠のモデルとブランチは、AI が知らせた物に替わっていきます。

モデル:

- AI のセッションが始まったときと、モデルを切り替えたときに、AI が知らせます
- Codex は、matomezu を使うたびに、今のモデルを知らせます。フックは要りません
- 知らせが無ければ、参加を頼んだときのモデルが出ます
- 知らせが 2 通りから届くときは、あとに届いた方が出ます

注: Codex で /model でモデルを替えると、次に AI が matomezu を使ったときから、新しいモデルが出ます。

ブランチ:

- AI が matomezu を使うたびに、AI の作業フォルダの git のブランチを読みます
- ブランチが替われば、すぐワークルームの枠に出ます
- 次のときは出ません: git が無い、作業フォルダが git のリポジトリでない、ブランチに居ない

注: ブランチを読むのは、受け入れて「準備中」が済んだ参加者だけです。
注: AI から、参加者のモデルやブランチを読む事はできません。人が画面で見るための物です。

Claude Code は、matomezu のプラグインを入れれば、モデルを知らせます（上の「Claude Code のプラグイン」）。

ほかの AI でモデルを知らせるには、AI のフック（セッションが始まったとき・モデルを切り替えたときに動くもの）で `matomezu model` を呼びます。

- フックが受け取った入力を、そのまま渡します（標準入力）
- `--host` に、AI のプログラムのプロセス id を付けます
- matomezu が起動していないときは、何もしません

注: 参加の前にモデルを知らせても、参加したあとのワークルームの枠に出ます。

#### /clear のあと

Claude Code で /clear を使うと、セッションが替わります。替わっても、同じ参加者のまま続きます。

- matomezu のプラグインを入れているときです（上の「Claude Code のプラグイン」）
- ワークルームも、一覧の行も、そのままです

### ワークルームを引き継ぐ

新しく参加する AI を、今あるワークルームに入れられます。これを「引き継ぐ」と呼びます。引き継げるのは、次のワークルームです。

- 空室
- いる参加者が「静か」か「準備中」のワークルーム

引き継ぐと、ワークルーム名・鳥・配色はそのまま、新しい AI が入ります。前の参加者は、参加者のリストから外れます。

引き継ぐかどうかは、参加を受け入れるときに選びます。

1. 参加要求の郵便のダイアログで「受け入れる」を押す
2. 「ワークルームに入れます」のダイアログの上で「引き継ぐ」を選ぶ
3. 「引き継ぐ参加者を選ぶ」の一覧から、1 つを選ぶ
4. 「受け入れる」を押す
5. 「（名前） を引き継ぎますか」と出る。「引き継ぐ」を押す

- 「新しく始める」と「引き継ぐ」は、引き継げるワークルームが 1 つ以上あるときだけ出ます
- 生きている参加者のいるワークルームは、一覧に出ません
- 一覧の行には、鳥・ワークルーム名・AI とモデルと環境・参加した時刻が出ます。モデルは、ワークルームの枠と同じく今のモデルです（上の「モデルとブランチ」）
- 空室の行には、AI とモデルと環境の代わりに「空室」と出ます。参加した時刻は出ません
- 引き継ぐときは、ワークルーム名・鳥・配色を選びません
- 確かめの段で「戻る」を押すと、ダイアログに戻ります

AI に前のワークルームを続けさせる:

1. AI に、続けるワークルーム名を伝えて参加を頼ませる
2. 届いた参加要求の郵便から、受け入れのダイアログを開く
3. 初めから「引き継ぐ」が選ばれ、その名前のワークルームが選ばれている
4. 「受け入れる」、確かめの段で「引き継ぐ」を押す

注: そのワークルーム名の参加者が生きているときは、AI は断られ、郵便も届きません。AI がチャットでそう伝えます。
注: 空室の名前を伝えても、同じに選ばれています。

新しく始めて、名前が引き継げるワークルームと同じとき:

「新しく始める」でワークルーム名を引き継げるワークルームと同じにして「受け入れる」を押すと、確かめの段が出ます。ボタンは 3 つです。

- 戻る: ダイアログに戻ります
- 前のを破棄して新しく始める: 前のワークルームを消して（参加者がいれば外して）、同じ名前・選んだ鳥・配色で新しく始めます
- 引き継ぐ: そのワークルームを引き継ぎます。選んだ鳥・配色は使わず、前のままになります

注: 確かめの段の間に、そのワークルームの参加者が生きている状態に戻ると、「引き継ぐ」と「前のを破棄して新しく始める」は押せなくなります。「戻る」で戻って選び直します。

## 17. プラグイン

ブックのタイプやアイテムは、プラグインで足せます。AI に頼めば作ってくれます。開発者向けの詳しい資料は別にあります。

プラグインは、テーマを足すこともあります。足したテーマは、そのテーマが向くタイプのブックでだけ、ブックの設定や箱・リストのダイアログに出ます。

プラグインは、郵便の種類を足すこともあります。AI が郵便箱を読むとき、一覧にその郵便の題が出るかは、プラグインしだいです（14 章「AI が郵便箱を読むとき」）。

プラグインは、タスクボードのチケット履歴の題を足すこともあります（18 章「チケット履歴」）。

プラグインは、横断検索のモードを足すこともあります（19 章「横断検索」）。

プラグインは、操作を止めることもあります（例: あるブックをゴミ箱に入れない、あるタイプのブックを作らない）。

- 止められた操作のボタンや選択肢は、出ないか、薄くなって押せません
- AI が行っても断られます

プラグインを足したり外したりすると、AI に頼めることも変わります（16 章「AI がブックを読むとき」）。

## 18. タスクボード

タスクボードは、作業を「チケット」にして、「レーン」に並べて進める物です。AI がチケットを足したり、レーンを移したりします。

ボードとチケットは、コントロールセンターで見ます（下の「プロジェクトの一覧」「ボード」）。カードを押すと、チケットを 1 つ見て直す画面が開きます（下の「チケットスクリーン」）。チケットを足すのは、今は AI に頼みます（下の「AI に頼めること」）。

### プロジェクト

タスクボード 1 枚を「プロジェクト」と呼びます。プロジェクトは次を持ちます。

- 名前（30 字まで）
- チケットプレフィクス: チケットの番号の頭（例: `T-`）。プロジェクト設定では「タスクプレフィクス」と出ます
- レーン: チケットを分ける列（名前は 10 字まで）
- 完了のレーン: 終わったチケットを置くレーン。レーンの中の 1 つか、無し（下の「チケットを完了にする」）
- チケットタグ: チケットの種類（名前は 10 字まで）
- チケットサイズ: ボードのカードの大きさ（下の「チケットサイズ」）
- 閉じているか

チケットプレフィクスの決まり:

- 英字 1〜3 字で書く（例: `T`・`ABC`）
- 最後にハイフンを 1 つ付けられます（例: `T-`・`ABC-`）
- ほかのプロジェクトと同じにはできません（大文字と小文字は同じとみなします）

名前・チケットプレフィクス・レーン・完了のレーン・チケットタグ・チケットサイズは、プロジェクト設定で直します（下の「プロジェクト設定」）。

### 標準のプロジェクト

タスクボードが入ってから初めて matomezu を起動したとき、プロジェクト「標準」が 1 つできます。チケットプレフィクスは `T-` です。

レーン:

| レーン | AI への指示 |
|---|---|
| 未着手 | タスク追加、と言われたらここにチケットを追加し、適切なタグを設定する |
| 作業中 | チケットを割り当てられたら、このレーンにチケットを移動する |
| 完了 | コミットがmainにマージされ、残作業が無くなったら ticket-complete で完了にする |

チケットタグ:

| タグ | AI への指示 |
|---|---|
| タスク | 通常のタスク。指定が無い場合はこのタグをつける |
| バグ | 既存機能の不具合を起票する場合に付ける |

- 完了のレーンは「完了」です
- チケットサイズは M です。「完了」のレーンだけ S です（下の「チケットサイズ」）
- 完了のレーンの指示は、チケットを完了にする時を AI に伝えます（下の「レーンとタグの指示」）。`ticket-complete` は、AI がチケットを完了にするときに使う物の名前です
- 作られるのは 1 度だけです。起動し直しても、もう 1 つはできません
- 文は、作ったときの言語で入ります。あとで言語を変えても、訳し直されません

注: どのレーンにも入らないチケットは「未分類」になります。

### プロジェクトの一覧

コントロールセンターの左の列の「プロジェクト」に、プロジェクトが 1 つ 1 行で並びます。

- 見出し「プロジェクト」を押すと、開く・閉じるが替わります。初めは閉じています。読み直すと、閉じた状態に戻ります
- 行には、左から、つまみ・チェック・プロジェクトの名前が並びます
- 1 つも無ければ「プロジェクトはありません」と出ます

ボードを出す・隠す:

1. 見出し「プロジェクト」を押して、一覧を開く
2. 出したいプロジェクトの行のチェックを入れる
3. プロジェクトの画面の上に、そのボードが右から入る

- チェックを外すと、ボードが右へ出ていきます
- いくつでも、同時に出せます
- まだ一度もチェックを変えていなければ、一覧の先頭のプロジェクトだけが出ます

並べ替える:

1. 行の左のつまみを押したまま、動かしたい所までドラッグする
2. 離すと、そこに入る

- ボードも、一覧と同じ順に並びます
- ドラッグしている間、離すと入る所に、線が出ます（下の「並べ替えの線」）
- 新しくできたプロジェクトは、一覧の後ろに、名前の順で入ります
- 閉じたプロジェクトは、一覧に出ません

並びと、出しているボードは、利用者の設定として残ります。読み直しても、そのままです。ほかの窓にも同じに出ます。

注: この 2 つは、設定画面には出ません。一覧で変えます。
注: 変えられないようになっているときは、つまみが出ず、チェックも押せません。
注: ワークルームの枠の「ボードで見る」を押したときも、ボードが出ます（16 章「ボードで見る」）。

### ボード

プロジェクトの画面の上に、出しているボードが縦に並びます。

1 枚のボードに出る物:

- 上の題の帯: プロジェクトの名前
- 右上: 歯車「プロジェクト設定」（下の「プロジェクト設定」）と、最大化のボタン（下の「最大化」）
- レーン: 左から、プロジェクトのレーンの順に、横に並びます

レーンに出る物:

- 上の題の帯: 左から、並べ方のボタン（下の「並べ方」）・レーンの名前・最大化のボタン
- その下: チケットのカード（下の「チケットのカード」）

- 題の帯をドラッグすると、レーンの順を替えられます（下の「レーンを入れ替える」）
- カードがレーンに入りきらないと、レーンに縦のスクロールバーが出ます。レーンがボードに入りきらないと、ボードに横のスクロールバーが出ます。どちらも細いバーです
- AI がチケットを足したり、レーンを移したりすると、すぐカードに出ます
- どのレーンにも入らないチケットは、「未分類」のレーンに出ます

注: 「未分類」のレーンは、プロジェクト設定の「未分類を表示する」がオンのときだけ出ます。出ていないときは、未分類のチケットはボードに出ません（下の「プロジェクト設定」）。
注: 横断検索でチケットを絞っている間は、ボードの上に「検索中: …」の印が出て、当たったチケットだけがレーンに残ります（19 章「チケットのモード」）。

### チケットのカード

カードの形は、チケットサイズで変わります（下の「チケットサイズ」）。ここでは M のカードを書きます。

1 枚のカードに出る物:

- 左上: 番号（チケットプレフィクスと、4 桁にそろえた番号。例: `T-0003`。太字）
- その下: チケットの名前。長いと、1 行で「…」で切れます
- 下の左: チケットタグのバッヂ。タグの色で塗られます。タグが無ければ出ません
- 下の右: 優先度。段の名前と、5 本の棒です
- 右上: 担当のワークルームの鳥。担当が無ければ出ません

優先度:

| 段の名前 | 色の付く棒 |
|---|---|
| 最小 | 1 本 |
| 小 | 2 本 |
| 中 | 3 本 |
| 大 | 4 本 |
| 最大 | 5 本 |

タグのバッヂ:

- 付いたタグが、プロジェクト設定の「チケットタグ」の順に並びます
- 1 行に入るだけ並びます。入らない分は「+2」のように数で出ます
- 「+2」にポインタを乗せると、残りのタグの名前が出ます

担当の鳥:

- 担当が 1 つなら、その鳥が出ます
- 2 つ以上なら、鳥が重なって出ます。先頭（主の担当）のほかは薄くなります
- 重ねて出るのは 3 羽までです
- 鳥にポインタを乗せると、担当の数が「2人」のように出ます

注: カードの上の辺に乗る鳥は、担当の鳥とは別です。「ボードで見る」で来た鳥です（16 章「ボードで見る」）。

カードを押すと、そのチケットのチケットスクリーンが開きます（下の「チケットスクリーン」）。

### チケットサイズ

カードの大きさを、L・M・S の 3 つから選べます。

| サイズ | カードに出る物 |
|---|---|
| L（大） | M と同じ物。名前は折り返して全部出ます。タグのバッヂは 3 行まで並びます |
| M（中） | 番号・名前・タグのバッヂ・優先度・担当の鳥。名前は 1 行で「…」で切れます。タグのバッヂは 1 行に入るだけです |
| S（小） | 番号と名前の 1 行だけ。長いと「…」で切れます |

決める所:

- プロジェクトのサイズ: プロジェクト設定の「全般」（下の「全般」）
- レーンのサイズ: プロジェクト設定の「レーン」で、レーンごとに（下の「レーン」）

- レーンのサイズが「継承」なら、プロジェクトのサイズになります
- 「未分類」のレーンは、いつもプロジェクトのサイズです
- 新しいプロジェクトは M です。完了のレーンだけ S です

注: S のカードには、タグのバッヂ・優先度・担当の鳥が出ません。

### 並べ方

レーンの中のカードの並べ方を、レーンごとに変えられます。初めは、番号の大きい順（新しいチケットが上）です。

1. レーンの題の帯の、左の並べ方のボタンを押す
2. 並べ方の小窓が開く
3. 項目を選び、向きを決める

小窓の項目:

| 項目 | 比べる物 |
|---|---|
| id | チケットの番号 |
| 優先度 | 優先度の段 |
| 最終更新 | チケットを最後に直した時刻 |
| 種別 | チケットタグ（下の注） |

1 行の操作:

- チェック: その項目を使うか
- 右のボタン「昇順 ↑」「降順 ↓」: 押すと向きが替わります。チェックが外れていれば、入ります
- 左のつまみのドラッグ: 項目の順を替えます。ドラッグしている間、離すと入る所に線が出ます（下の「並べ替えの線」）

- チェックの入った項目を、上から順に比べます。上の項目で同じなら、次の項目で比べます
- 例: 種別を上・優先度の降順を下にすると、タグごとに、優先度の高い順に並びます

注: 種別は、付いたタグを、プロジェクト設定の「チケットタグ」の順に並べて比べます。まず 1 つ目のタグを比べ、同じなら 2 つ目を比べます。タグの無いチケットは最後です。
- どれもチェックしなければ、並べ替えません
- 小窓の外を押すか、Escape を押すと閉じます
- 項目を 1 つでも使っている間は、並べ方のボタンの見た目が変わります

注: 並べ方は、その窓の中だけで覚えます。読み直すと、初めの並べ方に戻ります。

### 最大化

ボードやレーンを広げて、画面いっぱいで見られます。

ボードを最大化する:

1. ボードの右上の最大化のボタン（ポインタを乗せると「最大化」）を押す
2. ほかのボードが畳まれ、左の列とワークルームの枠が画面の外へ退く
3. 戻すときは、同じ所の「元に戻す」を押す

レーンを最大化する:

1. レーンの題の帯の、右の最大化のボタンを押す
2. そのレーンがボードの幅いっぱいに広がり、ほかのレーンは畳まれる。カードは折り返して並ぶ
3. ボードを最大化したときと同じく、ほかのボードが畳まれ、左の列とワークルームの枠が退く
4. 戻すときは、レーンの「元に戻す」を押す

- 最大化できるのは、ボード 1 枚か、レーン 1 列だけです
- ボードを最大化してからレーンを最大化した場合、レーンを元に戻すと、ボードを最大化した所に戻ります
- 最大化しているボードを一覧で隠すと、最大化も解けます

注: 最大化は、その窓の中だけで覚えます。読み直すと、元に戻ります。
注: 書庫の画面を前に出している間は、ボードを最大化していても、左の列は退きません。

### レーンを入れ替える

ボードの上で、レーンの順を替えられます。

1. 動かしたいレーンの題の帯を、押したままドラッグする
2. 入れたい所のレーンの上まで運ぶ。離すと入る側の辺に、線が出る（下の「並べ替えの線」）
3. 離すと、そこに入る

- 題の帯の、並べ方のボタンと最大化のボタンは、ドラッグに使えません。帯の残りの所をつかみます
- つかめる所には、つまみの絵は出ません。入れ替えられるときだけ、帯の上でポインタがつかむ手に変わり、帯の色が少し変わります
- 「未分類」のレーンも、同じに動かせます
- 替えた順は、プロジェクトのレーンの順になります。プロジェクト設定の「レーン」の並びも、ほかの窓のボードも、同じ順になります
- 題の帯の字は、選べません

注: 直せないプロジェクトのレーンは、動かせません。
注: レーンを最大化している間は、動かせません。

### 並べ替えの線

ドラッグで順を替える所では、ドラッグしている間、離すと入る所に線が出ます。

- 線は、離すと入るすき間の真ん中に出ます（行やレーンの縁には重なりません）
- 縦に並ぶ物は横線、横に並ぶレーンは縦線です

線が出る所:

- プロジェクトの一覧（上の「プロジェクトの一覧」）
- 並べ方の小窓の項目（上の「並べ方」）
- ボードのレーン（上の「レーンを入れ替える」）
- プロジェクト設定のレーンの一覧（下の「レーン」）

### レーンとタグの指示

レーンとチケットタグは、それぞれ AI への指示（プロンプト）を持ちます。AI は、チケットを足す・動かすときに、この指示に従います。

例: 標準のプロジェクトの指示では、AI に「タスク追加: ログイン画面の文言を直す」と頼むと、AI は「未着手」にチケットを足し、タグを付けます。

完了のレーンの指示には、チケットが終わったとみなす時を書きます。AI は、その時が来たらチケットを完了にします（下の「チケットを完了にする」）。

- 例: 「コミットがmainにマージされ、残作業が無くなったら ticket-complete で完了にする」
- 「このレーンに移す」とは書きません。完了のレーンへは、移すことができません。完了にすることでだけ入ります

- 指示を変えられるのは人だけです
- 指示は、プロジェクト設定の「タグプロンプト」「レーンプロンプト」で書きます（下の「プロジェクト設定」）

### プロジェクト設定

プロジェクトの名前・タスクプレフィクス・チケットサイズ・チケットタグ・レーンを直すダイアログです。

開く・閉じる:

1. ボードの題の帯の、右上の歯車「プロジェクト設定」を押す
2. ダイアログ「プロジェクト設定」が開く
3. 左のタブ「全般」「チケットタグ」「レーン」を押して、右の中身を切り替える
4. 直したら「保存」を押す。ボードに出ます
5. やめるときは「キャンセル」を押す。直した物は捨てます

- タブを切り替えても、入れた値は残ります
- 保存できないときは、「保存」が押せません（下の「保存できないとき」）

注: 閉じたプロジェクトは、設定を直せません（下の「人だけができること」）。

#### 全般

| 入力Form | 書く物 |
|---|---|
| プロジェクト名 | プロジェクトの名前（30 字まで） |
| タスクプレフィクス | チケットの番号の頭（上の「プロジェクト」の決まり） |
| チケットサイズ | L・M・S のボタンから 1 つ選ぶ（上の「チケットサイズ」） |

- プロジェクト名とタスクプレフィクスは、空にはできません。空だと「必須」と出ます
- タスクプレフィクスには、決まりに合わない字は打てません
- ほかのプロジェクトと同じタスクプレフィクスだと「ほかのプロジェクトで使っています」と出ます

#### チケットタグ

左にタグの一覧、右に選んだタグの「タグプロンプト」が出ます。

1 行に並ぶ物（左から）:

| 物 | 使い方 |
|---|---|
| 色 | 押して、6 色の見本から選ぶ。カードのバッヂの色です |
| タグ名 | タグの名前（10 字まで）。鉛筆のボタンを押して直す（下の「名前を書く・消す」） |
| 有効 | チェックを外すと、そのタグを使わない（上の「チケット」） |

- 行を押すと選べます。右の「タグプロンプト」に、そのタグの AI への指示を書きます
- 「タグ追加」を押すと、空の行が足され、タグ名の入力Formに入ります

#### レーン

上に「未分類を表示する」のスイッチ、左にレーンの一覧、右に選んだレーンの「完了レーンにする」のスイッチ・「チケットサイズ」・「レーンプロンプト」が出ます。

1 行に並ぶ物（左から）:

- つまみ: 押したままドラッグすると、レーンの順を替えられます。ボードのレーンも、この順に並びます。ドラッグしている間、離すと入る所に線が出ます（上の「並べ替えの線」）
- レーン名: レーンの名前（10 字まで）。鉛筆のボタンを押して直す（下の「名前を書く・消す」）

- 行を押すと選べます。右の「レーンプロンプト」に、そのレーンの AI への指示を書きます
- 「レーン追加」を押すと、空の行が足され、レーン名の入力Formに入ります

注: ボードの上で、レーンの題の帯をドラッグしても、順を替えられます（上の「レーンを入れ替える」）。

「未分類を表示する」:

- オンにすると、一覧に「未分類」の行が出ます。ボードにも「未分類」のレーンが出ます
- 「未分類」の行も、つまみで並べ替えられます
- オフにしても、「未分類」の並びの位置は残ります

注: 「未分類」の行には、レーンプロンプトとチケットサイズがありません。

「チケットサイズ」:

選んだレーンのカードの大きさです（上の「チケットサイズ」）。「完了レーンにする」の下、レーンプロンプトの上に出ます。

| ボタン | カードの大きさ |
|---|---|
| 継承 | プロジェクトのサイズ（「全般」で選んだ物） |
| L・M・S | そのサイズ |

- 足したばかりのレーンは「継承」です
- 変えた物は、「保存」を押すまで残りません

「完了レーンにする」:

選んだレーンを、完了のレーンにするスイッチです（上の「プロジェクト」、下の「チケットを完了にする」）。レーンプロンプトの上に出ます。

1. 左の一覧で、完了のレーンにしたいレーンを押す
2. 右の「完了レーンにする」をオンにする
3. ほかのレーンが完了のレーンなら、確かめのダイアログが出る（下の表）

| 押すボタン | 起きる事 |
|---|---|
| 変更する | 選んだレーンが完了のレーンになる。前のレーンは完了のレーンでなくなる |
| やめる | 何も変わらない |

ダイアログの文: 「完了レーンに「（今の完了のレーンの名前）」が設定されています。変更しますか？」

- オフにすると、完了のレーンは無しになります
- 完了のレーンは、プロジェクトに 1 つまでです
- 足したばかりのレーンも、名前を書けば完了のレーンにできます
- 完了のレーンにしたレーンを消すと、完了のレーンは無しになります
- 完了のレーンにすると、そのレーンのチケットサイズが S になります。あとで変えられます
- オフにしても、チケットサイズは戻りません
- 変えた物は、「保存」を押すまで残りません

注: 名前の無い行と「未分類」の行には、スイッチが出ません。
注: 新しいプロジェクトは、「完了」が初めから完了のレーンです。

#### 名前を書く・消す

チケットタグとレーンの名前は、同じ決まりで書きます。

名前は、ふだんは字だけで出ます。すぐ右に、鉛筆のボタン（ポインタを乗せると「名前を編集」）が出ます。

1. 鉛筆のボタンを押す
2. 名前が入力Formになる
3. 書き換えて、Enter を押すか、入力Formの外を押す
4. 字だけの表示に戻る

- Esc を押すと、書き換える前の名前に戻して終わります
- Enter で終えても、保存はしません。保存は、ダイアログの「保存」です
- 足したばかりの行は、初めから入力Formです
- 行を消すには、名前を空にして入力Formを離れます
- ほかの行と同じ名前にすると、赤い枠と「名前が重なっています」が出ます
- 長い名前は、字だけの表示では「…」で切れます。ポインタを乗せると、全部が出ます

ほかの行と同じ名前のまま離れたとき:

| 行 | 起きる事 |
|---|---|
| 足したばかりの行 | 行が消える |
| 前からある行 | 開いたときの名前に戻る |

注: 大文字と小文字は、別の名前とみなします。

#### 保存できないとき

次の間は、「保存」が押せません。

- プロジェクト名か、タスクプレフィクスが空
- タスクプレフィクスが、ほかのプロジェクトと同じ
- チケットタグか、レーンの名前が重なっている

保存のときの知らせ:

| 知らせ | わけ |
|---|---|
| 未分類に移るチケットはボードに出ません | チケットの入ったレーンを消していて、「未分類を表示する」がオフ。保存はできます |
| ほかで直されました。開き直してください | 開いている間に、ほかの窓などで同じプロジェクトが直された。保存されません |

完了のレーンを替えたとき、選んだレーンにいるチケットに、担当か今のチケットがあれば、保存は断られます。先にそのチケットを完了にします（下の「チケットを完了にする」）。

- 「ほかで直されました」と出たら、「キャンセル」で閉じ、歯車から開き直して直します
- 開いている間にプロジェクトが閉じられると、ダイアログはすぐ閉じます

### チケット

チケットは次を持ちます。

- 番号: プロジェクトごとの通し番号。チケットを消しても、その番号は使い回しません
- 名前（50 字まで）
- 本文（マークダウン）
- レーン
- チケットタグ: いくつでも付けられます。同じタグは 2 つ付きません
- 優先度: 5 段階。既定は真ん中です
- 担当: 受け持つワークルームの並び。先頭が主の担当です
- 足した者（人か、AI のワークルーム）と、足した時刻
- 最後に直した時刻
- ロックしているか

- チケットタグは、使うかどうかを持ちます。使わないタグは、新しく付けられません。もう付いているチケットはそのままです
- レーンを消すと、そこにいたチケットは、未分類として扱います
- タグを消すと、そのタグはチケットから外れたものとして扱います

注: 使わないタグを一度外すと、付け直せません。
- 担当のワークルームを消すと、そのワークルームは担当に無いものとして扱います
- 最後に直した時刻は、中身が変わったときだけ進みます

注: AI が足したチケットは、足したときのワークルームの名前・鳥・配色を写して持ちます。あとでワークルームを変えたり消したりしても、写しはそのままです。
注: チケットを足した事は、下の「チケット履歴」の行になりません。足した者と時刻は、チケットが持ちます。

### チケットのロック

ロックしたチケットは、直せず、消せません。

- ロックは、AI も掛けられます
- 外せるのは人だけです
- ロック中も、チケット履歴の行は足せます

注: ロックは、チケットスクリーンの帯のロックで掛け外しします（下の「チケットスクリーン」）。

### チケット履歴

チケットごとに、作業の記録を 1 行ずつ残せます。これを「チケット履歴」と呼びます。

1 行は次を持ちます。

- 題
- 書いた事
- 書いた者（AI なら、書いたときのワークルームの名前・鳥・配色の写し）
- 書いた時刻

題:

| 題 | 書くとき |
|---|---|
| 状況 | 作業がどこまで進んだかを知らせる |
| プラン | 何をどうするかを、する前に知らせる |
| 質問 | 作業が止まる・変わる事を、人に尋ねる |
| 本文更新 | チケットの本文を直した（チケットスクリーンが書きます。下の「本文を直したときの履歴」） |
| 完了 | チケットを完了にした（完了にしたときに書かれます。下の「チケットを完了にする」） |

- 行は足すだけです。あとから直せず、消せません
- 行を足しても、チケットの「最後に直した時刻」は進みません

注: 本文更新の行は、書いた事を持ちません。画面には「本文を更新しました」と出ます。
注: 完了の行は、書いた事を持ちません。完了で外した担当を持ちます。
注: 題は、プラグインが足すこともあります（17 章）。
注: 画面では、ワークルームの今のチケットの履歴が、ワークルームの枠で見られます（16 章「ワークルームの枠」）。どのチケットの履歴も、チケットスクリーンで見ます（下の「チケットスクリーン」）。

### 今のチケット

AI は、自分のワークルームが今取り組んでいるチケットを知らせます。これを「今のチケット」と呼びます。

- ワークルームごとに 1 つです
- 取り組んでいるチケットが無いときは、無しと知らせます
- 人に見せるための物です。ほかの動きは変えません

注: 今のチケットを知らせられるのは、ワークルームに入った AI だけです。人は知らせられません。
注: AI は、自分のワークルームの分だけ知らせられます。
今のチケットは、コントロールセンターの次の所に出ます。

- ワークルームの一覧の行の、名前の下の 1 行（16 章「ワークルームの一覧」）
- ワークルームの枠の、現在のタスクの列（16 章「ワークルームの枠」）

ボードのどこにあるかは、現在のタスクの列の「ボードで見る」で、鳥が教えます（16 章「ボードで見る」）。

### チケットを完了にする

作業が終わったチケットは、AI に完了にしてもらいます。例: 「T-0001 を完了にして」

完了にすると、一度に次の事が起きます。

1. チケットが、プロジェクトの完了のレーンへ移る
2. チケットの担当が、みな外れる
3. そのチケットを今のチケットにしていたワークルームは、今のチケットが無しになる
4. チケット履歴に「完了」の行が足される。外した担当の名前が付きます

- 完了のレーンへ入れられるのは、完了にするときだけです
- 完了のレーンにいるチケットには、担当を付けられません
- 完了のレーンにいるチケットは、今のチケットにできません

- AI は、完了のレーンの指示（レーンプロンプト）に書いた時が来たら、チケットを完了にします（上の「レーンとタグの指示」）

完了から戻す:

1. AI に、チケットのレーンを、ほかのレーンへ直してもらう
2. 担当が要れば、付け直してもらう

注: 戻しても、外した担当は戻りません。
注: 完了のレーンは、プロジェクト設定の「レーン」の「完了レーンにする」で決めます（上の「レーン」）。

### AI に頼めること

- プロジェクトの一覧を読む（下の「一覧に載らない物」）
- チケットの一覧を、番号の順で読む。プロジェクトで絞れます（下の「一覧に載らない物」）
- プロジェクトやチケットを 1 つ、全部読む。いくつかを一度に全部読むこともできます（20 件まで）。プロジェクトを読むと、チケットサイズも分かります
- プロジェクトを足す。名前とチケットプレフィクスを伝えます。2 つ目からは、ほかと違うチケットプレフィクスを伝えます。レーンとタグは、標準のプロジェクトと同じ物で始まります
- プロジェクトを閉じる・開け直す。人が頼んだときに行います
- チケットを足す。足すプロジェクト・名前・本文・レーン・タグ・担当・優先度を伝えます。担当は、足すときから付けられます（先頭が主の担当）
- チケットの名前・本文・優先度・レーン・タグ・担当を直す。タグと担当は、並びを丸ごと伝えます（担当は先頭が主の担当）
- チケットをロックする
- チケット履歴に、題を選んで 1 行書く。本文更新の題は、書いた事なしで書けます
- チケットを完了にする（上の「チケットを完了にする」）
- チケット履歴を読む。チケットで絞れます
- 自分のワークルームの今のチケットを知らせる・無しにする
- ワークルームごとの今のチケットを読む
- 言葉でチケットとチケット履歴を探す（19 章「AI に探してもらう」）

チケットを足すとき、言わなかった物:

| 物 | 入るもの |
|---|---|
| レーン | 未分類 |
| タグ | タグなし |
| 優先度 | 真ん中 |

レーン・タグ・担当は、名前で頼めます。

- 例: 「レーンは作業中、タグはタスクとバグ、担当は sub1 で足して」
- レーンとタグの名前は、そのプロジェクトの物です。担当の名前は、ワークルームの名前です
- 名前は、ぴったり同じに書きます。大文字と小文字は分けます（前後の空白は除きます）
- 無い名前を伝えると、AI は選べる名前の一覧を受け取ります。その中から選び直せます

注: 同じ名前のワークルームが 2 つ以上あると、その名前では担当に付けられません（断られます）。
注: 「unsorted」という名前のレーンを名前で頼むと、未分類になります。

足すと、AI はチケットの番号（チケットプレフィクス付き。例: `T-0001`）を受け取ります。プロジェクトを足すと、そのチケットプレフィクスと、レーン・タグの名前を受け取ります。

断られるとき:

- 閉じたプロジェクトに、チケットを足す
- 閉じたプロジェクトを、開け直すほかに変える
- ほかのプロジェクトと同じチケットプレフィクスで、プロジェクトを足す
- そのプロジェクトに無いレーン・タグや、使わないタグを付ける
- 同じタグを 2 度並べる
- ロックしたチケットを直す
- 担当に、同じワークルームを 2 度並べる。無いワークルームを担当に足す
- 伝えた名前に当たる物が 2 つ以上ある
- ワークルームに入っていない AI が、チケットを足す・履歴を書く・今のチケットを知らせる
- 完了のレーンへ、チケットを足す・移す
- 完了のレーンにいるチケットに、担当を付ける・今のチケットにする
- 完了のレーンが無いプロジェクトのチケットを、完了にする
- もう完了しているチケットを、完了にする

注: チケットを、ほかのプロジェクトへ移すことはできません。
注: 一覧は一度に 100 件までです。多いときは、AI が絞って読みます。

#### 一覧に載らない物

AI が読む一覧には、既定では次の物が載りません。

| 一覧 | 載らない物 |
|---|---|
| プロジェクトの一覧 | 閉じたプロジェクト |
| チケットの一覧 | 完了のチケット（プロジェクトの完了のレーンにあるチケット） |

- 載らなかった物があると、AI はその数を知ります
- 完了のレーンが無いプロジェクトのチケットは、全部載ります
- 載らない物も、頼めば読みます。例: 「完了したチケットも一覧して」「閉じたプロジェクトを一覧して」
- 載らない物を含めて全部読むことも、載らない物だけを読むこともできます

注: 1 つのプロジェクトの完了のチケットだけなら、プロジェクトと完了のレーンで絞っても読めます。
注: 載らない物の一覧も、一度に 100 件までです。続きは読めません。完了のチケットが 100 件を超えると、一覧では残りに届きません。

### 人だけができること

- プロジェクトの名前・チケットプレフィクス・レーン・完了のレーン・チケットタグ・チケットサイズを直す（上の「プロジェクト設定」）
- チケットを消す
- チケットのロックを外す（下の「チケットスクリーン」）

閉じたプロジェクト:

- チケットを足せません。もうあるチケットは直せます
- プロジェクト設定を直せません
- 閉じる・開け直すのは、AI に頼みます（上の「AI に頼めること」）

注: チケットを消す画面は、まだありません。

### チケットスクリーン

チケットを 1 つ見て直す画面です。コントロールセンターの上に、右から滑り込んで重なります。

開く・閉じる:

- 開く: ボードのチケットのカードを押す。チケットを指した URL を開いても開きます
- 横断検索の全文のモードで、当たった行を押しても開きます（19 章「全文のモード」）
- 閉じる: 左上の「戻る」か、ブラウザの戻るを押す。右へ滑り出ます
- 開いている間は、読み直しても開いたままです
- 開いている間、下のコントロールセンターは操作できません

注: 開いたまま、ブックスクリーンへ行けます（Escape か、下の行の「コントロールセンター」）。コントロールセンターへ戻ると、チケットスクリーンが開いたままです。

注: 郵便や AI から開く方法は、まだありません。
注: 無いチケットを指すと、「このチケットはありません」と出ます。

画面は、左の枠と右の枠に分かれます。

左の枠（上から）:

| 物 | 中身 |
|---|---|
| 帯 | 「戻る」・題「チケット」・ロック（下の「ロックを掛ける・外す」） |
| 番号とタグ | 番号（チケットプレフィクスと 4 桁。例: `T-0001`）と、チケットタグのバッヂ・「＋」（下の「タグを付ける・外す」） |
| 名前 | 名前と、鉛筆「名前を編集」 |
| 起票日時・最終更新 | 足した時刻と、最後に直した時刻 |
| 担当 | 担当のワークルームの鳥と名前。並びの順です。いなければ「—」 |
| 優先度 | 5 段のスライダー（最小・小・中・大・最大） |
| ナレッジ | 「本文」。押すと、右の本文の枠を出し入れします |
| 履歴 | チケット履歴の一覧（下の「履歴を見る」） |

右の枠:

- 本文の枠（下の「本文を見る・直す」）
- 質問の枠（下の「履歴を見る」）

開いたときの見せ方:

- 本文の枠が出ていて、プレビューで見せます
- 最大化していません
- 質問の枠は出ていません

注: 見せ方は、開くたびに、この形に戻ります。

#### 名前を直す

1. 鉛筆「名前を編集」を押す
2. 名前を書く（50 字まで）
3. Enter を押すか、ほかの所を押す。すぐ反映します

- Escape を押すと、直すのをやめます
- 空にして決めると、元の名前に戻ります

#### タグを付ける・外す

番号の右に、付いたタグのバッヂが、プロジェクト設定の「チケットタグ」の順に並びます。

付ける:

1. バッヂの右の「＋」（タグを付ける）を押す
2. まだ付いていないタグの一覧が出る
3. 付けたいタグを押す。すぐ反映し、一覧は閉じます

外す:

- バッヂの右の × を押す。すぐ反映します

- 一覧は、外を押すか Escape を押すと閉じます
- 一覧に出るのは、使うタグだけです
- 付けられるタグが残っていなければ、「＋」は出ません

注: 使わないにしたタグは、付いていればバッヂが出ます。× で外すと、付け直せません。

#### 優先度を変える

スライダーのつまみを動かします。離したときに反映します。

- キーで動かすと、1 段ごとに反映します

#### 本文を見る・直す

本文の枠の帯には、4 つの見せ方のボタンと「最大化」が並びます。

| 見せ方 | 出る物 |
|---|---|
| 編集 | マークダウンの原文だけ |
| 縦分割 | 原文とプレビューを左右に |
| 横分割 | 原文とプレビューを上下に |
| プレビュー | プレビューだけ |

本文を直す:

1. 「編集」「縦分割」「横分割」のどれかを押す
2. 原文を書く。打つたびに反映します

- 「プレビュー」では直せません
- 日本語の変換中は、変換が決まってから反映します
- 本文が空なら、プレビューに「（本文なし）」と出ます

本文を直したときの履歴:

本文を直してチケットスクリーンから離れると、チケット履歴に 1 行足されます。題は「本文更新」、書いた事は「本文を更新しました」、書いた者は利用者です。

離れるのは、次のときです。

- 左上の「戻る」を押す
- 開いているチケットが、ほかのチケットに替わる

- 何度打っても、離れたときに 1 行だけです
- 本文を直さずに離れたときは、足されません
- 名前や優先度を直しても、足されません
- AI やほかの窓が本文を直した分は、足されません

最大化:

- 「最大化」を押すと、本文の枠が広がります。左の枠は「戻る」だけに畳まれます
- 「元に戻す」を押すと、左の枠が戻ります
- ナレッジの「本文」を押しても、最大化は解けます

#### 履歴を見る

履歴の一覧は、新しい順に、日ごとにまとめて並びます。一番下は、起票の行「チケットを起票しました」です。

1 行に出る物:

- 時刻
- 題のバッヂ（状況・プラン・質問など）
- 書いた事。長ければ「…」で切れます。ポインタを乗せると全文が出ます
- 書いた者の鳥。ポインタを乗せると、ワークルームの名前（人なら「利用者」）が出ます

完了の行は、書いた事の所に「完了」と、外した担当のワークルームの名前が並びます（例: 「完了 sub1」）。

注: 消したワークルームの名前は出ません。

質問を見る:

1. 題が質問の行の、吹き出しを押す
2. 右に質問の枠が入る。書いた者の鳥・名前・時刻と、質問の全文が出ます
3. 「閉じる」で閉じる

- 開いている質問の吹き出しは、色が付きます
- 質問の枠は、本文の枠の上に重なります

注: 履歴に行を書く事は、画面からはできません。AI が書きます。画面が足すのは、上の「本文を直したときの履歴」の行だけです。

#### ロックを掛ける・外す

帯のロックを押すと、チケットのロックを掛けます。ロック中にもう一度押すと、外します。

ロック中は:

- 名前の鉛筆が出ません
- タグの × と「＋」が出ません
- 優先度のスライダーが薄くなり、動かせません
- 本文の原文を直せません

注: 見ること・見せ方を変えること・質問を開くことは、ロック中もできます。

#### 直している間

名前を書いている間と、本文の原文にカーソルがある間は、AI はそのチケットを変えられません。断られます。

- 名前を決めるか、原文の外を押すと、AI はまた変えられます

## 19. 横断検索

横断検索は、言葉で、いくつものプロジェクトのチケットとチケット履歴をまとめて探す物です。

### 開く・閉じる

- 開く: コントロールセンターの利用者パネルの、虫メガネ「横断検索」を押す
- 閉じる: 虫メガネをもう一度押す、パネルの閉じるボタン、Escape
- 左のサイドパネルなので、開いたままタスクボードやほかの画面が見えます

パネルに出る物（上から）:

1. モードのボタン: 「チケット」「全文」
2. 言葉の欄
3. 選んだモードの中身（下の「チケットのモード」「全文のモード」）

- 初めて開いたときは「チケット」のモードです
- 開き直すと、最後に選んだモードで開きます

### 探される物

| 物 | 探される所 |
|---|---|
| チケット | 番号・名前・本文 |
| チケット履歴 | 書いた事 |

- 大文字と小文字は分けません
- 1 字や 2 字の言葉でも探せます

注: カードの番号（例 `T-0012`）で打っても当たります。言葉の欄は空白で分けた語のどれかに当たれば残ります。

### チケットのモード

当たったチケットだけを、タスクボードに残します。

1. 「チケット」のモードを選ぶ
2. 言葉を入れる。プロジェクト・タグ・優先度の小さなボタンを押して選ぶこともできます。言葉の欄のすぐ下に、残るチケットの数が「N 件」と出ます
3. 当たったチケットだけが、タスクボードのレーンに残ります（右の領域が書庫の画面なら、書庫が引っ込んでタスクボードが出ます）
4. 当たったチケットのプロジェクトが、表示するプロジェクトになります。入りきらないときはスクロールになります

選べる物:

| 群 | ボタン |
|---|---|
| プロジェクト | プロジェクトの名前。初めは、今タスクボードに出しているプロジェクトが選ばれています |
| タグ | 「タグなし」と、プロジェクトの名前の見出しごとに並ぶタグ（タグの色のボタン） |
| 優先度 | 最小・小・中・大・最大（チケットカードの大きさを選ぶ部品と同じ見た目。複数選べます） |

- ボタンは押すと選ばれ、もう一度押すと外れます
- 同じ群の中では、どれかに合えば残ります
- 言葉と群どうしは、全部に合うものだけが残ります
- 「タグなし」は、タグを付けていないチケットに合います
- 言葉は、チケットの番号・名前・本文のほかに、そのチケットの履歴に当たっても残ります
- 完了のチケットも探されます

絞りを解除する:

- パネルを閉じても、絞りは残ります
- 絞っている間は、パネルの中の件数の下に「検索中: …」の印が出ます。入れた言葉と、選んだプロジェクト・タグ・優先度の数が出ます。タスクボードの上には出ません
- 印の × 「絞りを解除」を押すと、全部のチケットが戻ります

注: 言葉もボタンの選びも空にすると、絞りは消えます。
注: 絞りを残したまま開き直すと、前の言葉が欄に戻ります。

### 全文のモード

当たった物を、パネルの中に一覧で出します。

1. 「全文」のモードを選ぶ
2. 言葉を打つ。打ち終えて少し待つと、一覧が出ます
3. 行を押すと、そのチケットのチケットスクリーンが開きます。パネルは開いたままです。チケットスクリーンを開いたまま別の行を押すと、積まずに中のチケットだけが替わり、戻る矢印 1 回でコントロールセンターに戻ります

1 行に出る物:

- 当たった物の種類（チケット・チケット履歴）
- 何に当たったかの名前（チケットの番号と名前。チケット履歴の当たりは、そのチケットの名前）
- 当たった所の前後（入れた言葉に当たった所は赤字になります）

- 一度に 20 件まで出ます。もっとあると「ほかに N 件」が出て、押すと続きが出ます
- チケット履歴に当たった行を押すと、その履歴のチケットが開きます
- 完了のチケットも探されます
- 当たりが無いと「当たりなし」と出ます

注: 探せないときは「検索できませんでした」と出ます。

### AI に探してもらう

AI も、言葉でチケットとチケット履歴を探せます。

- 例: 「印刷のことが書いてあるチケットを探して」
- 言葉をいくつか伝えると、どれかに当たる物を探します
- 名前に当たった物が、本文に当たった物より先に並びます
- 言葉は探すだけです。「完了していない物を全部」のような問いには、AI は一覧を読みます
- AI は、当たった数と、当たった物ごとの短い説明と前後を受け取ります
- 一度に受け取るのは 20 件まで（多くて 50 件）です。続きも読めます
- 種類やプロジェクトで絞って探せます

一覧に載らない物（18 章「一覧に載らない物」）:

- 既定では、一覧に載らない物（完了のチケットなど）は当たりません。外した数は AI に分かります
- 頼めば、完了のチケットも含めて探すことも、それだけを探すこともできます。例: 「完了したチケットも含めて探して」

注: 画面の横断検索は、完了のチケットも含めて探します。AI の既定とは違います。

### プラグインと横断検索

プラグインは、横断検索にモードを足すことがあります。足したモードは、モードのボタンに並びます。AI に頼めば作ってくれます。開発者向けの詳しい資料は別にあります。

## 20. スクラップ

スクラップは、ページの一部を切り抜いて、別のページに貼る物です。

- 中は、元のページをそのまま描きます。写しではありません
- 元のページを直すと、スクラップの中もすぐ変わります
- 中は見るだけです。中の物は押しても選べず、直せません

使う順:

1. 元のページで切り抜く。切り抜いた物はスクラップトレイに入る
2. 置きたいページを開き、スクラップトレイから置く
3. 置いたスクラップの範囲や大きさを、あとで直す

### 切り抜く

1. 次のどれかで「スクラップを切り抜く」を押す
   - ページのタブを右クリック（そのページを切り抜きます）
   - 図面・フローチャート・ツリー・ディレクトリ構成図の紙の何も無い所を右クリック（開いているページを切り抜きます）
   - マークダウンの上の行・ペインの見出し・プレビューのペインを右クリック（開いているページを切り抜きます）
   - スライドのブックでは、ページ一覧のサムネイルを右クリック
2. 「スクラップを切り抜く」のダイアログが開く。ページ全体の絵に、見る範囲の枠が重なる
3. 見る範囲を決める（下の「見る範囲」）
4. 「トレイに入れる」を押す
5. 切り抜いたスクラップがスクラップトレイに入る。図面・フローチャートでは、左サイドパネルにスクラップトレイが開く

- 図面・フローチャート・ツリー・ディレクトリ構成図・マークダウン・スライドの、どのページも切り抜けます
- 「キャンセル」か Escape で、切り抜かずに閉じます

注: ツリー・ディレクトリ構成図・マークダウン・スライドでは、トレイは開かず「スクラップトレイに入れました」と出ます。置くときは、図面かフローチャートを開いてからトレイを開きます。

### 見る範囲

切り抜くダイアログと、置いたスクラップの設定のダイアログは、同じ作りです。ダイアログで決めるのは、見る範囲です。

- どちらのダイアログも、窓の幅と高さのほぼいっぱい（9 割）に開きます。ページの絵は、その中いっぱいに出ます
- 枠の中をドラッグすると、枠が動きます
- 枠の角と辺をドラッグすると、枠の大きさが変わります
- 切り抜くダイアログを開いたときは、範囲はページ全体です
- 枠はページの外へは出ません

注: 置いたときの大きさは、ダイアログでは決めません。置いたあとに四隅を引いて変えます（下の「置いたスクラップの大きさを変える」）。

### スクラップトレイ

切り抜いたスクラップを置いておく所です。左サイドパネルに開きます（2 章「左サイドパネル」）。

開く:

1. 図面かフローチャートのページを開く
2. フッタメニューのツールボックスの右の「スクラップトレイを開く」（点線の四角とトレイの絵）を押す
3. 左サイドパネルに、スクラップトレイだけが開く

- 図面・フローチャートで切り抜いたときも開きます
- もう一度「スクラップトレイを開く」を押すと閉じます
- 開いたまま、ステージのブックをツリー・ディレクトリ構成図・マークダウン・スライドに替えると、トレイは閉じます

注: 「スクラップトレイを開く」は、図面とフローチャートを開いているときだけ出ます。スクラップを置けるのが、この 2 つだけのためです。
注: 郵便箱を開く「左サイドパネルを開く」のタブには、スクラップトレイは並びません。

1 つのスクラップの行に出る物:

- スクラップの絵
- 元のブックとページの名前（「ブック › ページ」）
- ×（スクラップを消す）

- 新しく切り抜いた物が上に並びます
- 1 つも無ければ「スクラップはありません」と出ます
- matomezu を起動し直しても残ります

### 置く

1. 置きたい図面かフローチャートのページを開き、スクラップトレイを開く
2. スクラップトレイの、置きたいスクラップを押す
3. 紙の上に点線の影が出る。置きたい所で押す

- 置いたときの大きさは、紙の幅と高さの半分に収まる大きさです
- 置いても、トレイに残ります。同じスクラップを何か所にも置けます
- 置き方は、ほかのアイテムと同じです。置けない所では影が薄くなります（7 章「置く」）
- 置いたスクラップには、箱と同じように線を引けます（9 章）

注: 切り抜いた範囲が紙の半分より小さければ、切り抜いたときの大きさ（等倍）のまま置きます。

### 置いたスクラップを直す

1. 置いたスクラップをダブルクリックする（右クリックの「設定」でも開きます）
2. 「スクラップの設定」のダイアログで、見る範囲を直す（上の「見る範囲」）。絵の右の列で、枠線も決められる（下の「枠線」）
3. 「OK」を押す

- 見る範囲を広げると、置いたスクラップも同じ割合で大きくなります
- 紙に収まらなければ、ダイアログは閉じずに「紙に収まりません」と出ます
- 動かす・消すは、ほかのアイテムと同じです（7 章）

### 置いたスクラップの大きさを変える

1. 置いたスクラップを押して選ぶ
2. 四隅のどれかをドラッグする
3. 引いている間、その場で大きさが変わって見える。縦横の比は保ったまま、中の絵も一緒に大きく・小さくなる
4. 離すと、その大きさに決まる

- 横だけ・縦だけに引いても変わります。大きく動かした方に合わせます
- 見る範囲は変わりません
- つかめるのは四隅だけです。辺ではつかめません
- 紙の端と、元のページの 10% から 400% までの大きさで止まります
- 隣の形を押しても、スクラップは縮みません

注: つかめる所に印は出ません。四隅にポインタを置くと、ポインタの形が変わります（7 章「大きさを変える」）。

### 枠線

置いたスクラップのまわりの線です。「スクラップの設定」のダイアログの、絵の右の列（「元のページを開く →」の上）で決めます。

- 置いたときは、細い枠線が引いてあります。色はテーマの線の色です
- 「枠線」のスイッチを切ると、枠線が消えます
- スイッチが入っている間、その右で枠線の色を選べます（7 章「色を選ぶ」）
- 色の「なし」を選ぶと、テーマの線の色に戻ります

注: 色の「なし」は、枠線を消すのではありません。消すときはスイッチを切ります。

### 元のページを開く

スクラップが見せているページを、同じステージで開きます。次のどちらかで開きます。

- 置いたスクラップを右クリックし、「元のページを開く」を押す
- 「スクラップの設定」のダイアログで「元のページを開く →」を押す。ダイアログは閉じます

- 元のページが別のブックにあれば、そのブックを開いてから、そのページを開きます
- 元のページが無ければ（「No Data」のとき）、何も起きません

注: ダイアログで範囲か枠線を直した後は、「元のページを開く →」を押せません。先に「OK」で決めるか、やめてから開きます。
注: スクラップトレイを開いたまま、元のページがツリー・ディレクトリ構成図・マークダウン・スライドなら、トレイは閉じます。

### トレイから消す

1. スクラップトレイの行の × を押す
2. 「このスクラップをトレイから消しますか？」と出る。「スクラップを消す」を押す

- 元に戻せません
- 紙に置いたスクラップは消えません

### 中が描けないとき

| 出る物 | わけ |
|---|---|
| 「No Data」 | 元のページが無い（消したなど） |
| 輪の印 | スクラップの中のスクラップをたどると、同じページに戻る |

どちらも、灰色の点線の枠で出ます。

### AI とスクラップ

AI に頼めること:

- スクラップトレイを読む（新しい順に 20 件まで）
- 図面とフローチャートに、スクラップを置く。どのページの、どの範囲を、どの倍率で見せるかを伝えます
- 置いたスクラップの大きさを変える。幅か倍率を伝えると、高さは比で決まります
- 置いたスクラップの枠線を変える。なし・色・テーマの線の色から選べます

人だけができること:

- 切り抜いてスクラップトレイに入れる
- スクラップトレイから消す
